# 補助役の装備・職業を再比較する版 0.25

単独火力中心の候補選抜で、アンコール・ロンド役が手順比較より前に落ちる問題へ対処した。各キャラについてアンコール、ロンド、ラッキーの開幕効果の候補を最大2種類ずつ別枠で保持する。通常の探索結果を保持したまま、その上位2手順を起点に、主力以外の1〜2人の職業・武器・装備を入れ替えて再評価する。

追加の戦闘評価は最大768回で、通常探索と同じ全体上限を共有する。主力が使っていた装備を取り上げず、交換した補助役側で所持数が競合する防具・こころだけを外す。武器の所持不足は候補を棄却する。補助役のMP・こころコスト・習得スキル・最低能力・指定された順序条件は共通の戦闘検証を通す。

## 同じ条件での比較

Dオルゴデミーラ（強）、HP480,000、収録済み初期所持品とレベル、2ターン、手動操作。こころ道解放済みと全員の魔人Lv20/40会心枝25%を明示した検証条件で、前版429,414 → 今回484,013。モデル上は2ターンでHPを削り切る。補助役をケキちゃん装備の役と大神官のアンコール役へ入れ替え、主力の追加行動を作った。倍率・敵HP・耐性・装備ステータスの変更はしていない。

ただし味方順の速度乱数保証はfalse、敵速度不明で先制保証もfalse。安定討伐を示す結果ではない。仮値を含む収録データによるモデル検証で、実機実測でもない。実際のこころ道が未解放ならこの結果を適用しない。

解放を指定しないデフォルト条件は416,294で前版と同じ。残HP63,706。未指定の解放状況を自動的にオンにはしない。

## 検証

固定フィクスチャ tests/fixtures/support25.json と tests/damage25.cjs で、追加行動のまとまり・所持数競合の除去対象・武器不足の棄却・予算ゼロと上限・入力の不変性・484,013の再現とMP非負・主力装備保持を検証する。通常の全テストも実施する。

公開後のブラウザ確認で、アギロゴス条件では装備候補が同じ所持品へ集中してチーム候補が空になり、手順探索0回で停止する問題も再現した。通常候補が空の場合だけ、各人最大64候補・チーム幅4の所持数調整を追加した。最大832組の候補検査で、後から参加するキャラ側の競合装備だけを外して組合せを作る。能力・コスト・武器の所持数は緩和せず、実ダメージは通常シミュレーターで再計算する。初期所持品によるアギロゴス条件は手順780回・364,794ダメージまで探索を継続できた。特殊ギミックを解決したり、討伐を成立させた結果ではない。

## 残る課題

配置を変更した結果の手順・補助対象・速度判定・編集欄の番号は「キャラ番号」ではなく「左から何人目」と明記した。育成記録のキャラ番号と配置番号の混同を防ぐ。

大域最適化ではない。候補の保持数・装備の局所探索・補助パターンに上限がある。手動手順の順序は速度乱数により崩れ得るため、画面の順序判定を確認する必要がある。仮値の実データへの置換、未収録効果、実機ダメージとの照合は引き続き必要。
