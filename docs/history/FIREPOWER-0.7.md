# 火力検証版 0.7

開発順は「火力計算の検証 → 敵・装備・バフ・スキルの手入力検証 → 装備と手順の自動選定」です。自動選定は試作として残し、新規拡張より計算の検証を優先します。

## 今回の変更

- 画面04「火力を手入力で検証」を追加しました。敵名、守備力、表示攻撃力、スキル倍率、ヒット数、直撃・会心、各補助状態を指定できます。
- 装備・こころを指定すると、収録された特殊効果を合計して入力欄に反映できます。攻撃力は実機の装備込み表示値を使い、装備能力値を二重加算しません。スキル名は記録用で、倍率や特性は手指定です。
- 計算上下限、1発と合計、補助後能力値、計算順序、入力記録を表示します。任意の実測値が範囲内か比較できます。条件はブラウザに保存します。
- 物理計算の二刀流補正を最終段階に移し、切り上げを適用しました。非会心への会心のひらめき倍率を除外しました。
- 手入力物理モデルで、テンション適用時の整数%丸め、フォース半減順序、敵テンションによる弱点縮小、根絶やし、レベルアップ／ダウン、会心種別の範囲を分離しました。

## 検証と根拠

公開検証式 https://github.com/AruDqw/dqw-damege-calc の2026-10-21取得版を参照し、丸め段階を照合しました。公式が公開した完全な内部式ではありません。通常・直撃の手計算、会心補助の適用条件、二刀流の丸め、テンション、敵弱点、根絶やしなど13件の追加テストと既存74件が合格しました。ブラウザで直撃1100%の5148〜5852、実測比較、装備の特殊効果読込を確認しました。

## 未完了と次の順序

1. 火力計算の検証を継続：呪文・ブレス・攻魔複合、各スキル固有式、ダメージ上限、実機測定との照合を追加する。現段階の新しい独立計算機は物理のみ。
2. 手入力機能の拡充：職業・こころ道・継承と条件付き効果、スキルの正式なデータからの選択、装備から能力値の完全な算出を追加する。現時点では装備効果に仮値・不足があり、実機の合計値で修正する必要がある。
3. 検証済みの共通モデルを自動選定に統一し、装備とスキル順を探索する。従来の自動選定では敵・スキル固定の仮定が残るため、正確性確認済みとは扱わない。

単発物理の計算に命中・ガード・シールド・敵行動・生存を含めません。したがって表示範囲だけでは確実な討伐や行動順を保証しません。参考記事のアギロゴス火力再現も未完了です。
