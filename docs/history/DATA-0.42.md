## 探索

ためを覚えるこころの候補をアームライオンのID固定から習得スキルによる検索へ変更。
はめつのゴーレムを含め、各枠を試して火力が高い配置を残す。
勇者のつるぎ＋魔人＋根絶やしだけの条件から、二刀流以外の物理候補へ対象を広げた。
無制限に候補を増やさず、8種の職業/武器組合せ・8件の準備装備候補の上限を設ける。

補助役の防具より主攻撃役へ必要な所持品を残す既存の競合解消は継続。
今回のデータ追加だけで八重霞900の実際の入力を再現したとは扱わない。
シールド、会心成立、敵耐性など未確認の条件から100万や2ターン討伐を保証しない。
