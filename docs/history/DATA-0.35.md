# 0.35 補助を集中する探索・バフ表示・計算予算

確認日：2026-10-23。ローカル保存のみ。公開サイトは未更新。

## 探索の変更

従来は通常攻撃を置いた手順の探索で評価上限に到達し、後段の補助役差し替えまで実行されないことがあった。上限の一部を先に確保し、攻撃役1人と補助役最大3人の「準備から攻撃まで完結した手順」を比較する。補助単発のダメージで候補を落とさず、補助の役割の組み合わせを残す。

おうえんは主人公の守り人のみ。守護天使の記憶による習得条件を、こころ道の解放指定から分離した。「習得済みとして比較」のチェックを実際の所持状況に合わせて変更できる。

どんぶりスライム、覚醒どんぶりキングを8能力・コスト・斬体補正付きで収録。覚醒側だけが特盛一丁を使用できる。最大MP5%、戦闘中1回、4行動の攻撃力または呪文威力2段階。表示攻魔を1.4倍する処理ではない。通常・覚醒の同時装備は禁止。初期の覚醒所持数は1。

神鳥の翼斧は0/4凸、ホーリーラッシュ、時空干渉と開幕延長を収録。調停者の盾からオーバードライブを習得する。最大MP10%、戦闘中1回、直後の再行動と3回の行動終了時延長を計算する。延長は元の持続+1が上限。おうえん・テンション・祈り自体は延長しない。連続呪文が発動している行動で延長されれば、その特性を次の通常行動へ持ち越す保守的モデル。

開幕の左隣効果は端から反対端へ届く。時空干渉の両隣対象は端をまたがない。両者の対象を分けてテストする。

## 領域

新世界を通常スキルとして使用し、先行している領域を上書きできる。赤・紫・青などの色条件を指定可能。色は発動者の実際の虹枠のこころから求め、数値だけを強制しない。指定色のこころを銃剣役へ確保してから、他のキャラの共有所持品を調整する候補も残す。

収録済みの会心率・暴走率、段階バフ、領域の率補正を集計し、既知の下限だけで100%に達する場合は確定側へ適用する。呪文は敵1体に限る。複数対象時の暴走率補正は未検証なので自動で確定扱いしない。大魔道士のゾーンによるやまびこ確定も反映する。

## バフ表示

行動直前・行動終了後の4人の有効なバフを記録。攻撃時の本人の強化を表示し、4人の前後比較は折り畳める。失効済みの過去の付与ログを現在の強化として表示しない。

「残N回」は本人の行動終了までの回数。再行動でも進むため、ゲームのターン数とは分けて表示する。祈りは通常行動開始回数、ためは次の対応攻撃まで。残1回は色で強調する。探索途中はスナップショットを省き、最終候補だけを再計算して表示データを生成する。

## 確率条件

暴走・やまびこ等は未確認の確率を推測して埋めない。利用者が入力した1判定あたりの発動率と、明示した独立仮定から「指定効果の同時発動率」を算出する。祈り等の確定効果は確率判定を増やさない。未入力または独立仮定がなければ未算定。下限を検索条件に指定したときは未算定の条件付き攻撃を通過させない。攻撃しないだけの0ダメージ手順も結果に残さない。

この値は行動順・命中・被弾・敵のギミックを含む討伐成功率ではない。実機と判定回数や相関が異なれば、入力値による積も一致しない。

## 探索時間とメモリ

- 短時間：装備16,000候補・手順2,500・約15秒の予算。
- 標準：装備40,000候補・手順6,000・約45秒の予算。
- 詳細：装備80,000候補・手順12,000・約120秒の予算。
- 計算済み手順を再利用。手順キャッシュは最大1,024件。
- こころ道なし/ありの比較で手順予算を共有し、追加こころなしの再探索でも同じ終了時刻を使う。
- 制限時間後は評価済みの候補を返す。処理単位で時刻を確認するので、表示時間は厳密な実行時間保証ではない。
- Workerで実行し、既存の中止ボタンを維持する。

初期プロフィール・ギガモンの短時間探索を開発環境で2回計測し、約10.0秒と17.1秒。装備16,000、手順2,500以内で終了した。後者は回帰テストとの並行実行で期限に達し、評価済み候補を返した。端末・負荷・所持品で変動するため、速度向上率や最適解は保証しない。

## 検証と残る範囲

補助3種の集中、呪文威力と表示攻魔の区別、延長不可・上限・左右の境界、盾由来のスキル解放・MP・再行動・回数制限、確率未算定時の扱い、色指定に対する所持品の確保、探索予算共有、実際の画面生成とHTML構造をテストする。

自動探索は引き続き最大2ターンの近似探索。超暴走・マナ、全職の特性、領域の防御・回復・解除処理、敵のシールドや特殊行動、全装備の網羅、実機との完全一致は未完了。暴走倍率は前版の代表倍率による比較を継承する。
