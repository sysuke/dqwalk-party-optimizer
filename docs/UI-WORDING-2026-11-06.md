# 基本画面の文言整理

コンテンツ選択・目的設定・結果・所持品管理の文言を、操作と意味が伝わる表現へ統一した。スキル名・職業名などゲーム内の名称は維持する。

| 以前 | 変更後 |
| --- | --- |
| 目的・目標 | 攻略の目的 |
| この条件で計算する | 編成と手順を探す |
| 成立条件を含む火力案も比較 | 条件つきの案も探す |
| メラガイアー軸 | メラガイアーを使う編成 |
| 未達・要調整 | すばやさの調整が必要 |
| 探索上限・詳しく再探索 | 比較しきれていない組み合わせ・時間をかけて探す |
| この結果の条件を変更 | 自分の所持品・レベルに合わせる |
| 性能・仮置き項目 | 性能と未確認の項目 |

条件つきの数値が保証値・平均値ではないこと、必要な発動・維持の確率が不明なことは見える位置に残す。敵の特殊ルール、仮シールドの割合・計算根拠は折り畳み、仮の値であることは見出しで示す。サンプル／未確認の登録内容／確認済みの登録内容を区別し、登録確認を計算精度の保証とは表示しない。

変更対象は表示文言と説明の配置。計算式・探索・登録形式・設定値・フォームの入力名は変更していない。同じ検証プロフィールの通常254,922・条件つき4,390,608と通常への復帰を実Workerで確認した。

検証：UI24件、登録状況4件・結果編集3件、Pages150参照。PC1107pxとスマホ390pxで入力導線・横はみ出し・JavaScriptエラーを確認。通常指定、装備不足、条件付き案の未発見、Workerの起動／応答エラーの表示も確認した。文言変更に合わせて既存UIテストの表示ラベルを更新し、テストは追加していない。
