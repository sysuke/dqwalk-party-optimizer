# 耐久・暫定シールド・攻撃スキル別の探索

2026-11-04。ユーザーの指示により、バハムートを「耐久優先・その中で早期討伐」の初期目標へ変更。シールドを未判定として除外する方式をやめ、仮値と明記して計算に含めた。既存の最短ターン・指定ターン火力・周回の目標も保持する。

## 観測と仮定を分ける

- ユーザーの観測：全体攻撃**1回**につき1人500〜700程度。1ターン合計とは確認されていない。
- 1ターンに全体攻撃1回を初期の仮定とし、回数とターン別回数を編集できる。`1,0,1,2` のように指定し、空欄以降は既定回数を使う。平均ダメージへ置き換えず、各ターンにまとめて受ける。
- 単体攻撃・追加攻撃・敵領域・被ダメージ上昇など、未入力の敵行動を勝手に補完しない。「全体攻撃だけの仮定で生存」と実戦での生存を分ける。
- 利用者が全候補共通の「1ターン合計被ダメージ上限」を詳細設定に入力した場合は、その値を優先する。装備別の守備・耐性から被ダメージを算出する完成モデルではない。
- 敵速度が未入力なら、従来通り敵先行の保守側。回復前に倒れた人を回復で復活させない。

## 回復

出典：[ペルセリア](https://9db.jp/dqwalk/data/20440)、[ラッキーフォーチュン](https://9db.jp/dqwalk/data/19790) を本文で確認。

- ラブ・ストリーム：全体の基礎回復150。攻撃と同じ行動・MP80。回復UPと追加詠唱/やまびこごとの回復回数は未確認のため、1行動1回の基礎値だけを含める。これは回復量の実測下限ではなく、参考計算の入力値。発動率や回復倍率を観測値から逆算しない。
- ひと夏のシーブリーズ：MP63。ユーザーの「300くらい？」を**仮入力300/人**として比較する。確定した回復下限ではない。入力を消した場合は量未確認として扱い、生存成功へ昇格させない。
- シーブリーズの攻回複合ダメージ・幸運・回復会心は未算定。回復行動として実際の行動枠を使い、攻撃部分を含まない参考ダメージであることを注記する。
- 最大HPを超える回復を切り詰め、実際に回復した量と支払ったMPを台帳へ記録。戦闘不能やMP不足で実行できなかった回復は加算しない。
- 約300を別の装備/職業にも使う比較は、全候補共通の仮定であり、回復魔力や防具別補正による実機再現ではない。

## 暫定シールド

[バハムートの攻略](https://9db.jp/dqwalk/data/20605)は、公式に割合が明示されていないためメガモンと同じ前提の10/20/30/50%を掲載している。この値を採用し、3難易度それぞれの最大HPから閾値を計算する。仮値であることを選択画面と結果に表示する。

火力比較でもシールド上限をHPへ反映する。ブレイク枚数、HPへの実適用、残HP、討伐ターンは同じ仮定に依存する。ブレイクと討伐は別判定。幻竜の0.5/1/1.5/2.5%を流用しない。仮シールドの結果は確定成功にしない。

## 探索順序と多様性

1. 所持品と育成済み職業から合法な装備候補を作り、耐性・種類耐性・SHTガード込みで攻撃をスクリーニングする。初期スクリーニングは最大48件。
2. 攻撃スキルを最大4系統選び、実在する補助役・回復役・自己強化を割り当てる。耐久では回復付き攻撃も残す。
3. 単独バフだけでなく、異なる役割のバフを組み合わせた手順を、MP・持続・使用回数・対象込みで通常の戦闘計算へ渡す。推定倍率の積を結果のダメージに使わない。
4. 9ターンのMP・HPを通算する。目標より早く倒したら、以後の被弾や回復は発生しない。
5. 耐久目標では想定内で生存できる候補を優先し、その中では早い討伐を優先する。生存未達しかなければ、途中で倒れたターンを表示し、達成扱いにしない。「全員生存を必須」を指定した場合は、未達・未確認の候補を除外する。500側と700側の比較も併記する。
6. 最終候補を主力攻撃スキル別に分ける。同じスキルの装備・配置違いや、全身全霊斬りの根絶やし違いで3枠を埋めない。最上位の候補は保持する。

バフの組合せを全列挙する最適化ではない。既存の段階探索と上限を保ち、探索順を改善したもの。到達できなかったダメージへ式を合わせない。必要最小のバフを証明したという意味でもない。

## 状態表示と検証

各キャラに「ゾーンあり」「テンション100」を付け、実際にその状態を使ったターンを保持する。9ターンすべてで同じ状態が続くと勝手に認定しない。率不明のゾーン・テンション・AI選択は、引き続き未算定の成立条件。

`tests/survival-strategy.cjs` でHP/MP台帳、回復前の戦闘不能、回復未入力、早期討伐、ターン別被弾、耐久優先の順位、攻撃スキル別候補、個別の状態、同じ手順の再計算一致を検証する。実機バハムートの9ターン完全再現を意味しない。
