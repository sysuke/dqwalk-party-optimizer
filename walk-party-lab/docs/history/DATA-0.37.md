# 0.37 大魔道士の魔響の詠唱

2026-10-23。魔響の詠唱を個別検証と編成・手順探索に追加。公開範囲は既存の所有者限定を維持する。

## 対応内容

- キャラごとにLv30の補助こころ道を指定。詠唱側を選択し、解放済みチェックと必要レベルを満たす場合だけ使用可能。未指定の保存データから両側を解放済みにはしない。
- 使用時は最大MPの20%を消費。攻撃呪文の威力に1.2倍を掛け、消費MPに1.5倍を反映。呪文威力の段階、装備補正、ためとは別に保持する。
- やまびこの入力発動率に1.6倍を掛け、100%で上限。発動時比較を選んだ場合だけ追加詠唱を計算し、倍率を理由に自動で必ず発動する扱いにはしない。
- 補助と直後のAI攻撃呪文をひとまとまりの1行動として扱う。持続は5回モデルで、補助設定直後に余分に消費しない。おうえん・祈り等を直後の攻撃前に失効させない。
- 直後だけAI選択の条件を付け、次の通常行動では手動選択を許可。真魔解放の継続する命令不可とは区別する。
- 装備探索は「こころ道解放」「詠唱側」「AIによる指定攻撃の仮定」を許可した場合、1ターン目から詠唱→攻撃を含む完結した手順を比較する。
- 行動ログにAI選択条件・補助後の持続保留を表示。再現率はAI選択率が未確認のため未算定とする。

## 使い方

「編成・結果」の詳細条件でキャラ別の大魔道士こころ道を選び、補助解放とAI比較を許可する。「装備とスキル順で検証」では各キャラの個人補正欄で同様に分岐を指定し、魔響の詠唱の直後に同キャラの攻撃呪文を追加する。

やまびこ発動率を入力する場合は、魔響による増加前の率を使う。AI選択率は勝手な値を置かず、未確認の条件として表示する。

こころ道の同じ枝にある全能力・全パッシブを一括実装したものではない。やまびこの威力上昇、装備とこころ道からの発動率の自動集計、フォースバーストは未対応。魔響の持続とアンコール等の追加行動、消費MP増加・マナ併用時の細かな丸めは実機照合を要する。現行のMPは切下げ〜切上げの範囲を記録し、足りるかは大きい側で判定。

## 検証

全507件合格。新規11件では、分岐・解放制限、即時攻撃と持続、祈り・おうえんの保持、MP境界、無料やまびこ、マナ併用、発動率補正、自動探索での選定とAI条件表示を検証。ゲーム実機との一致例数を意味しない。
