- はぐメタのお守り：MP8・速度16を収録。イオ耐性5%は被ダメージ計算へ未接続。直接の攻撃威力ボーナスはない。

- スラいいね！の勲章＋：速度25・体技5%・呪文3%を収録。天超えし竜牙の斬撃へ体技5%を加算しない。眠り耐性10%は未接続。
  出典：https://gamewith.jp/dq-walk/article/show/396459
- バトルマスターの極意書：装備として選べるよう登録。掲載効果はバトマス専用会心率4%。特級職へ適用する条件の照合待ちで、全職共通の会心率としては未接続。確定超会心の威力を増やす効果ではない。
  出典：https://game8.jp/dqwalk/638541
- 会心ガード軽減率不明の下限0〜軽減前上限に実測が入っても、照合を保留する。代表倍率・未完のモデルも同様。範囲内件数と保留理由は別に保存・表示する。古い照合記録は現在の式で再計算すれば保留理由を取得できる。

## 実測4件の状況

551・6,055：会心ガードの軽減率が独立に確認できていない。0〜上限という広い幅での範囲内を再現成功としない。時間レベル、こころ道、装着枠などもそろえる必要がある。

43,197・67,674：強化Lv4の個体に対応する種類/属性耐性が未確定。古代の遺跡の記事に通常の属性倍率は掲載されているが、その数値を強化Lv4へ無条件に転用しない。後者は超越領域の可能性があり、ゾーンだけを変えた対照実験ではない。

今回追加したアクセだけでは、これらの差が埋まるとはいえない。表示攻撃力1796は既に上書き入力する仕様で、能力値を再加算して火力を膨らませない。現時点では実測一致は未達。

## 追加テストの優先順

1. 同じキラーマシン2強化Lv4・同じ装備で、攻撃直前の全バフ、敵状態、通常/超越領域の表示、こころ道の各選択を保存する。まず条件を明確にする。
2. ゾーンなし/ありを比較する場合は領域と他のバフを固定し、各3〜5回の超会心1発を記録。各1発の差だけを固定倍率としない。
3. 会心ガードは、敵テンション・スキル耐性・味方強化をそろえて有無を比較できる場合のみ測る。他のバフも解除された比較は別条件として扱う。
