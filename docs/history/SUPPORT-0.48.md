# 0.48 待機の補助置換と攻撃兼補助の候補保持

防御・待機は一律禁止しない。4枚同時破壊を壊す早い攻撃や、効果が重複するだけの補助を強制するのではなく、完全な手順を再計算して改善する候補を選ぶ。

- 不死鳥のほむらのように攻撃しながら次行動者を強化するスキルを補助役のプールに保存する。従来はkind=attackのため補助の絞り込みから漏れていた。次行動者の配置も比較する。
- 最終候補で、一度きりの補助を前ターンの主力準備行動後へ移す候補を保持。空いた次ターンの枠で、4枚ブレイク後に攻撃する候補を比較する。
- 残る待機枠には、収録済み・実所持の補助つきこころ、武器、盾と、既存の補助用装備構成を比較する。どんぶりキング、ケキちゃん、ラーミアのムチ、神鳥の翼斧、領域用装備、オーバードライブ等を既存モデルの範囲で扱う。
- 補助役間でこころ・防具の所持数競合を調整し、主力の装備は借用しない。技能を失う変更は除外する。実測表示能力を指定した人物の装備を勝手に替えない。
- 4枚達成後は、不要な余剰の一撃火力より、実際の残HPとMP消費を比較する。同じ効果でMPだけ増える行動を有利としない。
- 待機を残す場合は理由を折り畳んで表示。防御の被ダメージ軽減は従来どおり自動計算せず、4人の行動完了に必要な準備待機として扱う。

比較件数は最大192件を共通探索予算内に予約。候補を絞る近似探索であり、未収録技能の補完や全補助の網羅ではない。

報告例の保存データで、4枚同時破壊を維持しながら待機2回→0回、残HP626,758→619,023となる候補を確認。補助を前倒し、不死鳥のほむら、ブレイク後のホーリーラッシュを使用。火力式の倍率は変更していない。ゾーン成立の前提や敵バフ未対応などの制約は維持する。

ラーミアのムチ参照：[みんドラ](https://9db.jp/dqwalk/data/12461)。不死鳥のほむらの火力・強化効果は既存実装を使用し、今回架空の効果を追加しない。

追補：主力の15%未満の小火力攻撃も補助置換の対象とする（候補の絞り込み基準であり採用条件ではない）。特盛など対象指定の補助はロンド等の次行動者強化より前に置く順番も再計算し、主力への効果先を守る。準備行動後への配置も比較する。採用は同じ戦闘モデルの実評価に従い、待機数を減らすだけの変更は優先しない。
