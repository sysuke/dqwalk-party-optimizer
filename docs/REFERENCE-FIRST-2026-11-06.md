# 火力の参考案を最初の計算で比較する

## 問題

公開版76d53b0の画像では、バハムート零式・9ターン・確率効果を仮定しない比較が301,087。比較ボタンを追加しても、求める「実戦で狙う価値のある装備・手順」より、会心・暴走・ゾーン・指定AI攻撃を使わない低い結果が入口に残っていた。下限の微増を推薦品質の改善とは扱わない。

保存プロフィールは未取得。画像で読めるゴッドハンド・ニンジャ・魔剣士・大魔道士を各Lv80、標準サンプル所持品とした合成ケースでも、通常9ターンは254,922。画像そのものや実測の再現ではない。

## 変更

バハムート3難易度の目標画面に「攻略の参考案を探す（必要な状態も比較）」を初期選択する。このモードの火力比較では、確率効果なしの探索の後、登録済みの装備・育成・使用許可で対応できるときだけ、必要状態を含む呪文案も自動探索する。所持品・敵・ターン数は変えない。耐久優先ではこの自動比較を行わない。

既存の「確率効果を仮定しない」を明示選択した場合は切り替えない。通常側と条件付き側は別探索で、各探索の設定上限を使う。計算量が最大約2回分になる。探索効率が2倍になったとは扱わない。

必要なのは主力のゾーン・呪文暴走・AIが指定呪文を選ぶこと。テンション100は追加しない。発動・維持は実機で満たす必要があり、成功率は未算定。通常時の保証火力や期待値として表示しない。画面で通常側の結果と並べ、通常条件だけへ戻して再計算できる。

装備・育成・こころ道／継承許可が不足するときは、不足する項目名を表示して通常側を残す。条件付き探索が候補未発見、またはWorkerの処理に失敗した場合は、確認済みの通常結果へ戻して理由を明記する。通常側を再探索する必要はない。確率下限を勝手に外さず、未所持品や職業を追加しない。

## 補助装備と全ターンの行動をまとめて変更

`DamageGoalSearch.complete` は、補助武器へ持ち替えた直後に旧武器の攻撃が未習得になると、補助手順を設定する前に候補を棄却していた。特に複数ターンで同じ弱い攻撃を使うケースを取りこぼす。

変更後は、候補化済みの小火力の通常攻撃だけを一旦待機へ置き換え、補助行動とまとめて検証する。既存の準備・補助・再行動の組、主力攻撃、シールド破壊につながる攻撃を削らない。次行動者を強化する補助は、複数ターンで主力の直前に使う案も全体評価する。MP不足・所持数・習得・行動順などは通常の戦闘モデルで再計算し、既存の探索予算を超えない。

構造回帰ケース：通常3ターン、主力のメラガイアー、他の1人が1発313の全身全霊斬り。持ち替え修正無効では39,588、有効ではラーミアのムチへ持ち替え、3ターンとも不死鳥のほむらを主力の直前へ置き54,834。ゾーン・暴走は指定していない。これは持ち替えの棄却を防ぐ構造テストで、バハムートの実機火力を検証した数字ではない。

## ブラウザ確認

実ChromiumとWorkerで、上記合成プロフィール・零式・9ターン・参考案の初期選択から計算。通常254,922と、条件付き4,390,608を自動で比較し、通常254,922へ復帰できることを確認。条件付き側980評価、発動率null、テンション0。登録JSON・敵・ターン数を維持。通常条件の約17倍改善ではなく、必要状態を追加した別案の提示である。

実機のダメージ式照合、ゾーン等の必要条件を減らす比較、速度と火力の両立、敵の領域・ガード解除・ギガアタック等は残る。今回の439万が利用者の保存戦力で出るとも、ゲーム内で再現済みとも扱わない。

検証：全706テスト（80ファイル）、UIの24テスト、Pagesの150参照を確認。データ・実測監査も実行。実Workerでの自動比較・復帰に加え、制御したWorker応答で明示した通常条件／必要装備不足／候補未発見／Worker起動エラー／Worker応答エラーを確認。未発見・エラー時は追加の通常探索をせず、確認済み結果の表示とJSON出力へ復帰する。
