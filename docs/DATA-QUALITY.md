## 残るデータ不足

最重要は全11職の基礎能力、敵の守備・速度・強化状態。18章と鉱脈は代表条件そのものが仮。装備を増やすだけでは、これらの誤差は解消しない。

オチェアーノ・しんぴの水晶の旧概算登録、ドラゴンコープスの旧概算経路の持続、ヘルコンドルの属性とくぎ範囲、蒼き竜王のMP回復接続などに確認事項が残る。詳細カタログと旧概算画面は利用範囲を区別する。verifiedModel=trueは全効果・実戦ギミックの検証完了を意味しない。

防具ではカミュ装備・世界樹の鎧下【滅】などの守備値未収録、条件付き耐性・職業限定値・凸追加値の不足が残る。未収録値を0とする処理と、実際の値が0であることは区別する。

## 再監査

`npm run audit:data` は全データを実際の順序で読み込み、ID重複、こころ8能力の欠損、スキル参照切れを検出する。最終値・出典・確認日・未対応注記もJSONへ出力する。

注記のキーワードによる仮値抽出は作業用。ヒットなしでも完全検証済みではない。出典に公開日がない値や、注記されていない不足は手動監査が必要。自動監査で外部サイトの数値までは検証しない。
