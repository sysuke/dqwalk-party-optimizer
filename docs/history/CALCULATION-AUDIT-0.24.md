# 補助手順の組み合わせ探索 0.24

既存の最良候補を保持したまま、探索回数の余りで二人の補助手順を同時に変更して評価する。ロンド、攻撃強化、スキル強化、アンコールを対象とし、ダメージは既存の戦闘シミュレーターを通して計算する。倍率・データ値の変更はない。

各キャラ最大8種類、上位6候補につき最大192回の追加評価。全体の評価上限を共有する。局所探索であり、武器の組み合わせ全体を網羅するものではない。単独では不利な補助二人の連携が有利になるケース、追加候補が負けても元の候補を保持するケース、回数制限、未所持スキルを生成しないことをテスト。

Dオルゴデミーラ（強）の初期所持品・レベル条件では下限416,294、HP480,000に対して残り63,706。前版と同じ。実機の測定値ではなく、今回の探索追加で討伐可能になったという結果はない。実測比較なしで100万へ倍率調整しない。

未解決: 候補絞り込みによる装備・職業組み合わせの取りこぼし、未照合の特殊効果・効果持続、実機ダメージとの照合。全属性・全スキルの完全再現を保証しない。
