# 0.46 確率ゾーン・テンションの成立時比較

03に主力ゾーンを仮定する条件とテンション段階の成立条件を追加。新しい画面の初期選択は主力ゾーン発動時、テンションは装備・手順の確定分のみ。プログラム/APIの未指定条件は従来どおり。

同じ装備・手順で、指定した確率ゾーン・テンションの前提なしと、成立時の乱数下限〜上限を並べる。他の呪文暴走等の指定条件は維持するため、「あらゆる確率効果なし」の値とは異なる。主力は仮定なしの実計算で最も合算ダメージを出した人物から選ぶ。4人全員にゾーンを勝手に与えない。

ゾーン・テンションの入力確率は、必要な攻撃まで状態を維持できた成立率として扱う。開始時ゾーンの抽選率を各攻撃ごとに再乗算しない。この率の自動推定、途中発動時刻・失効の確率過程、全員ゾーンの最適選択は未対応。率が不明なら未算定とし、目標値へ合わせて率を作らない。

単一条件は独立性仮定なしでも入力した成立率を表示。複数条件は、率が全て既知かつ独立性を利用者が仮定した場合のみ乗算。実現率下限に50を入力すれば50%以上を残す。未算定の候補はそのフィルターを通さない。討伐成功率ではない。

テンションの表示段階と既存の内部補正は区別する。すでに確定分が指定段階以上なら下げず、確率条件にも追加しない。参照：[公式スキル効果説明](https://walk.dragonquest.jp/web/help/show/140)。火力式の倍率を今回変更したものではない。

検索時に成立前提なしの主力を確かめ、成立時も在庫・MP・行動順を再計算するため、確定条件だけの探索より計算量が増える。既存の探索件数・時間上限を維持する。
