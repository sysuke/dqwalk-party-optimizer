# 防具・アクセサリーと最大火力探索 0.11

## 使い方

1. 「02 戦力を記録する」で実際の所持数・職業レベルへ変更。新規収録品は仮所持として追加される。既存の所持数0は維持する。
2. 「04 装備とスキル順で検証」で武器・こころ・敵・補助手順を指定。
3. 画面下の「最大ダメージの装備を探す」で攻撃と比較基準を選び、算出する。
4. 上位3候補の防具・心珠・アクセサリー、ダメージ範囲、元装備との差を確認。「この候補を装備欄へ反映」で選択できる。

## データ

最大強化0凸の17点を追加・照合。新たなる伝説・魔人・伝説の勇者の各3部位、ウロボロスのたて、ロトのせいなる盾、黄竜眼の指輪+、女神のゆびわ+、魔導将軍のゆびわ+、ドラゴンのオーブ++、ひかりのたま、ほのおのルビー+。

各データの出典はアプリの収集データ欄とJSONに保存。防具の生ステータスとレベル特殊効果を区別して合算し、晴れ限定の属性効果を条件一致時のみ適用。会心率は会心ダメージへ変換しない。固有敵補正・防御耐性・盾スキルは今回未算入として表示する。全防具・アクセサリーを網羅したデータではない。

## 算出の範囲

選択キャラの盾・頭・体上・体下・心珠2枠・アクセサリー2枠を全列挙。選択した1回の物理攻撃の乱数下限、または乱数上限を最大化する。武器・左手・継承・こころ・職業・手順・並び順と他の3人の装備を固定する。

4人で使っている固定武器・継承・こころと、他の3人の防具等の所持数を差し引く。アクセ同一品2個・二刀流への盾を除外。心珠は所持個数の範囲で同一品を許可。装備なしも候補に含む。実機攻撃力の上書きがある場合は、装備変更による差分を計算する。

候補10万組で停止し、その場合は探索済み範囲の最良と明示。列挙完了時のみ収録・所持・固定条件内の最良とする。上位3候補は同一装備順違いを重複させない。敵やバフ等の条件変更後は再探索が必要。

HP・生存・すばやさ・MPを制約にした探索ではない。速度が変わるため、指定手順の成立を別途確認する。武器・こころ・職業・複数ターン手順を同時に最適化する機能は未完了。呪文・ブレス・攻魔複合は今回の探索対象外。旧06自動選定への新防具データ接続も未完了。

## 検証

既存146件と新規17件のテストに合格。小さな独立全列挙との一致、所持数共有、実機能力値への差分、天候条件、会心率分離、探索打切り、Worker起動を確認。

初期の全所持モデルでは33,000組を約9秒で比較。選択攻撃の下限120,331から208,378へ増える構成（調停者3部位・ウロボロス盾・ガイア2個・ドラゴンのオーブ++・ひかりのたま）を返した。仮の職業基礎能力・等倍敵によるモデル内の比較であり、実機の最大火力保証ではない。
