# 0.44 火力目標からの手順探索

従来の装備・手順探索に、目標となる攻撃時状態を比較する独立した経路を追加。

1. 実際の装備で使える攻撃を、敵の耐性込みの戦闘計算で比較する。主力候補は4人から交互に評価し、斬撃・体技・呪文と属性の異なる系列も残す。
2. 使用可能な補助を単独で実行したときの主力攻撃への効果を測る。必要HPに届くと見込まれる組み合わせを先に、併用が必要な補助系列も別枠で比較する。この予測値は候補順だけに使い、最終火力には使わない。
3. 所持する装備・こころから得られる補助手順を組み立て、MP、持続、再行動、次行動者、在庫を通常の戦闘計算で検証する。単発候補では主力の他の攻撃を待機に置き換え、準備効果が残るか再計算する。根絶やし付き攻撃を後の攻撃へ移すときも一度だけ使用する。
4. 複数回攻撃する元の手順も比較する。単発未達を討伐成功とは表示しない。ギガモン等の最大火力方針には固定目標を強制しない。

表示：統合探索0.44、逆算経路の評価件数、候補の「火力目標と攻撃時の状態」。単発の不足値は総ダメージの不足値とは異なる。

範囲：逆算経路は既存探索で残した最大2種類の装備構成を起点にする。全装備・全バフ状態を厳密に逆算する完全探索ではない。各構成の追加評価は最大192件で共通予算・時間上限に従う。特定候補がこの経路を通らなければ状態欄は表示されない。既存の探索結果とも比較し、最終順位は戦闘計算結果で決める。

未対応：特殊シールドの段階目標、未収録の解除効果、全装備候補の網羅的な再割り当て。アギロゴスのシールド込みの勝利は依然としてこの経路では保証しない。検証対象は既存の火力モデル内での一致であり、実機の未知の補正を確定したものではない。
