# 行動順を保った火力装備の見直し

## 問題

速度調整は味方順が成立すると終了するため、外した装備の代わりに速度を増やさない火力装備を入れる余地が残っていた。複数の順序のうち1案だけを速度調整する制限も調べたが、今回はその工程を置き換えず、成立済みの案の装備を見直す。

## 変更

条件付きの長期火力比較で、味方順を満たした別案に未使用の評価枠が残っていれば、所持しているこころ・防具・心珠・アクセサリーを1枠ずつ入れ替える。最大2巡、戦闘全体の評価は最大24件、装備の組立て確認は合計2,048件まで。元の順序修正工程と合わせて160件以内、全体1,000件の上限・締切は維持する。残り枠がなければ追加しない。

候補の並べ替えには能力と補正による推定を使うが、採用には通常の戦闘計算を使う。所持数、装備制約、コスト、HP・速度条件、MP、全ターンの味方順、指定した敵速度と領域を再確認する。シールド反映後の有効ダメージが下がる案、既に達成した討伐や条件判定を失う案は採用しない。実機攻撃力・攻撃魔力を直接指定したキャラの装備は、この追加工程では変更しない。

`orderDamageRecovery:false` で無効化し、従来の速度調整と比較できる。通常条件・耐久・周回の順位や計算式は変更していない。

## 検証

```
npm run benchmark:roles -- --bahamut-order-recovery
node tests/conditional-order.cjs
```

標準サンプル・バハムート零式・5ターン・主力ゾーン／暴走／指定AI呪文の同じ条件で比較。

| 項目 | 無効 | 有効 |
| --- | ---: | ---: |
| 火力優先案（味方順未達） | 3,754,572 | 3,754,572 |
| 味方順が成立する別案 | 1,760,323 | 2,116,638 |
| 全体の戦闘評価数 | 972 | 996 |
| 順序修正と追加工程の評価数 | 134 | 158 |

追加は24評価・2,048組立て確認。味方順成立案の表示速度621／951／768／1,143を保ち、主力の心珠を見直せた。敵への先制は未確認、必要な確率効果の発動率はnull、`conditionsMet` はfalseのまま。実測・利用者の保存プロフィールの再現ではない。

架空の装備を使う小規模ケースも全組み合わせと照合し、速度条件を満たす最良43,090に一致（元41,722）。所持数不足、指定領域違反、有効ダメージの低下、期限・評価上限、実機能力指定を保護するケースを検証した。

実ChromiumとWorkerでも、火力優先3,754,572と味方順成立2,116,638を同じ1,000件上限で表示・展開できること、発動率不明と敵への先制未確認が残ることを確認。

## 残る制限

1枠ずつの候補を有限に絞る探索であり、大域最適ではない。複数枠を同時に替えなければ改善しない火力装備や、別の行動順の再調整は取りこぼしうる。必要なゾーン等を減らす比較、敵の領域・ガード解除、実機のダメージ・速度乱数との照合は引き続き未了。

検証結果：全707テスト（80ファイル）、配信150参照が通過。回帰テスト合格は実機一致や勝利の保証を意味しない。
