# 複数ターンの行動順と速度調整 0.26

全ターンをまとめて検査し、速度バフの変化、整数の切り捨て、厳密な先行条件を反映する。各ペアを別々に「あと何ポイント」と表示するだけでは、両立しない要求を見落とすため追加した。

## 判定

floor(表示速度×そのターンの速度倍率) > 相手の実効速度×入力乱数比 を同時に解く。追加行動は直前の通常行動と一緒に扱い、敵速度上限が登録されていれば先制条件も加える。表示速度1〜100,000の整数制約を単調な下限更新で解く。収束した場合は、現在の表示速度を下げずに成立させる同時調整目標を表示する。範囲内に解がなければ手順変更が必要と表示する。数学上の目標が所持装備で達成できることは意味しない。

速度比は利用者の入力モデルであり、実ゲームの速度乱数分布を新たに検証したものではない。敵速度未登録では先制は未判定。

## 装備の追加探索

有効候補を最大3件取り出し、数学上両立する順序に対して、こころ・防具・アクセ・心珠の1枠変更を比較する。各候補最大96回、通常の全体評価上限を共有する。武器・職業・スキル手順を保持し、候補ごとに所持数、HP、MP、コスト、実ダメージを再検証する。元の候補が討伐できている場合は討伐を失う変更を作業候補にも採用しない。

最短ターン方針では、同じターン数の討伐候補同士なら、入力した味方順を満たすものを操作数より先に比較する。最大火力方針の優先順位は変更しない。

局所探索であり、複数枠同時交換や全装備の網羅はしない。厳密な順序必須条件で初期の有効候補が0件の場合、条件を緩和した手順から復元する探索は未対応。

## 比較とテスト

Dオルゴデミーラ（強）484,013ダメージの既存手順は、速度比1.2では表示速度100,000以下の範囲に全ターンを満たす解がない。1ターン目の銃剣→アンコール役→ロンド役→勇者のつるぎと、2ターン目のアンコール役→ロンド役→勇者のつるぎ→銃剣が、速度効果の変化を含めても両立しない。条件どおり操作できた場合の火力結果は維持するが、安定討伐の結果とは扱わない。

初期所持品・レベルの自動選定は、解放指定なし416,294、解放・会心枝指定あり484,013で前版と同じ。速度比1.2で安定した2ターン討伐を新しく達成した結果はない。

収録装備の実ステータスを使う結合テストは、速度比1・待機のみの固定手順で、違反1組から0組へ改善する。実戦の速度比や討伐を再現するテストではない。

境界値、同速度、バフによる順序逆転、先制の小数境界、矛盾、所持数、MP、予算、入力の不変性を検証。小範囲の全数探索と、固定乱数で生成した4人・160組の制約系でも実現可否を比較した。新規12件と既存343件が通過。
