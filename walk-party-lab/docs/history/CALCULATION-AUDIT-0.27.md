# 役割交換と行動順の入れ替わり検証 0.27

単独火力中心の候補から、攻撃役と補助役の担当キャラを交換する候補も生成する。新しい担当キャラの育成済み職業、基礎能力、得意武器、こころ道、こころ色・コスト、所持数から再計算する。未育成職業や未解放技は追加しない。魔人から別職へ替える場合は根絶やしを使えず、武器の全身全霊斬りが使用可能な場合だけ置き換える。

補助が先に入る速度調整も比較する。速度候補をキャラ・装備枠ごとに残し、火力を失う極端な変更ばかりで探索枠を埋めないようにした。

## 固定順と結果の検証を区別

固定した1つの順番を保証できなくても、順番が入れ替わった全ケースでHPを削り切れる場合がある。このため、各ターンの実効速度Sに対し、利用者が入力した速度比Rの区間 [S, S×R] で起こり得る4人の順序を列挙する。同速・端点は両方の順番を含める。これは利用者の検証モデルであり、実ゲームの速度乱数の分布を測定したものではない。

アンコール等の追加行動は付与元の通常行動の直後に固定する。1ターン目の各順序を実行した状態から2ターン目の速度を再計算し、通常のダメージ・MP・敵行動シミュレーターで各ケースを評価する。各攻撃には乱数下限を使用する。最大576順序。途中打ち切り、MP不足、未検証・無効スキル等が1ケースでもあれば「全ケース討伐」にはしない。

役割候補は最大16構成、職業は各担当の上位2候補。追加の速度調整・順序検証を合わせて最大1,536回とし、通常探索の全体上限も共有する。最初に全ケース討伐を検証できた構成を残す近似探索で、大域最適化ではない。

## Dオルゴデミーラ（強）の比較

初期所持品と登録レベル、HP480,000、速度比1.2、2ターン、アンコール等の必要こころ道を解放済みとする条件。

旧484,013ダメージの固定手順は576順序中96順序でHPを削り切れず、最も低いケースは413,672だった。

担当を交換し、ゴッドハンドの勇者のつるぎ、ニンジャのケキちゃん、魔弾の剣士の銃剣、大神官のアンコールを使う構成では、起こり得る全36順序で2ターン以内にHPを削り切る。各ケースの乱数下限の最小値484,751、各ケース下限の最大値501,957、最大10操作。ケキちゃん側の表示すばやさ1,485、銃剣1,222。魔人の追加会心枝を指定しない自動選定でも同じ結果を再現した。

ダメージ式、装備データ、敵HP・耐性、入力速度比を調整して結果を合わせていない。指定した1つの順番の固定保証、敵への先制、未知の被ダメージによる生存、連戦全体、実機の実測を検証した結果ではない。職業基礎能力や収録装備に仮値が含まれる点も従来どおり。

解放指定なしのデフォルト条件は416,294のまま。必要なこころ道が実際に解放済みの場合だけ設定を有効にする。

## 検証

区間順序の全数照合、同速・端点、未検査ケース、MP不足、旧576順序の失敗再現、育成済み職業・得意武器・所持数・習得スキル、全36順序の自動算出と再生、追加会心枝への非依存、JSON保存、画面での成功・失敗・未確認条件の区別を検証した。
