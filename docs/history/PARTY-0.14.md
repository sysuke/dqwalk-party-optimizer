# 編成ラボ 0.14

02で所持品と各キャラの職業レベルを登録し、01で攻略先と方針を選ぶと、08で4人の職業・配置・装備・こころ・最大2ターンの操作手順をまとめて比較できます。アギロゴスは既存の06・07の専用ギミック検証へ進みます。

## 今回の追加

- 通常戦の敵を1〜4体登録。コンテンツの複数敵を読み込み、HP・守備力・系統・属性耐性を個別に編集。
- 全体攻撃と単体攻撃を区別し、単体攻撃の対象も探索。対象が倒れた場合は残HP最大の生存敵へ変更。
- 敵の残HPを独立して管理。1体への過剰ダメージで他の敵まで倒したことにしない。
- 生存敵数が減った後は、ロトの竜剣・はてんの月輪・祖竜【理】の銃剣などの敵数依存倍率を再計算。
- 敵ごとに属性と系統の補正を計算。開幕の種族条件は戦闘開始時の全敵を確認。
- 生存敵が複数なら、ランダム追撃の各敵への確定着弾を仮定しない。1体時のみ全追撃を下限へ加算。
- 攻撃ダメージと、過剰分を除いた有効ダメージを区別して表示。
- 選定した編成のスキル・補助対象・単体攻撃対象を変更し、08の中で再計算。結果JSONにも反映。
- 勇者のきあいため・極限集中の戦闘中1回制限を適用。

## 入力と結果の扱い

通常戦では08を利用してください。追加の敵は「敵を追加」から設定できます。速度・被ダメージ上限は、未確認なら空欄のまま使えます。その場合、先制・生存の条件成立は表示しません。

結果の「この手順を調整して再計算」から、装備を維持してスキルと対象を変更できます。追加行動の根拠と行数が合わない場合、未習得スキル、使用回数超過、MP不足は検出します。並びと行数を変える編集は対象外です。再計算後は、元の自動案の最適性を示すものではありません。

敵1体の候補は04へ保存して装備をさらに変更できます。複数敵の結果は08で確認しJSONで保存します。ブラウザに保存する所持品・職業レベルは従来どおり維持します。

## 現在の実用範囲と限界

収録済みの物理攻撃・攻魔複合・補助と、明示した条件で比較するツールです。全装備・全職業特性・全ボス行動を再現する完全なゲームシミュレーターではありません。シールドや特殊解除を持つボスを、通常戦のHP判定だけで討伐保証しません。

ランダム追撃は保守的な下限を使用します。複数敵への各上限を足した値は、同時成立するダメージを意味しません。1攻撃内で敵が倒れた後のランダム追撃の再分配、崩壊・消滅・火種・確率直撃・確率会心・みかわし等の全分岐は未再現です。敵数依存倍率は各攻撃の開始時の生存数を使います。

探索は候補を絞る方式です。探索上限と仮値を画面に表示します。最大2ターンの通常戦を扱い、長期戦の回復・蘇生や全出現パターンを通した周回の保証は対象外です。周回方針の無補給戦数は、毎戦同じ条件で開始する消費MPの目安です。

勇者のきあいための良い効果延長など、未反映効果は効果を捏造せず保守側で計算します。職業の素の能力に仮値が含まれる場合は02の実測能力で置き換えてください。実戦との完全一致は継続して照合が必要です。
