# 補助手順の探索修正（ローカル作業版）

2026-10-26。

## 原因と変更

月輪の相棒と継承ロンドの補助効果は計算エンジンに存在した。
不足していたのは、装備候補の生成と、ロンドの補助を攻撃役へ渡す手順の探索。

- 装備詳細の探索枠を使い切った場合も、装備済みブーメランからケキ継承の基本候補を生成する。
- ロンド補助の候補では、相棒が発動する月輪＋継承ケキの組合せを残す。最終採否は実際の全手順ダメージで比較する。
- 行動順にロンド役→攻撃役を追加。targetフィールドだけではロンドの補助先は指定できない。
- 継承元は0凸だけでなく、実際に所持している4凸も指定・消費できる。所有数の検査を省略しない。
- 新規初期設定は継承比較オン。既存保存設定でオフにした値は維持し、対象外であることを画面に表示する。

## 検証

同じ攻撃役（表示攻撃力1500・勇者のつるぎ・会心発生条件）と守備力1000の検証用敵で比較。
月輪継承ロンド後の攻撃33234〜37728、ケキのバイキルト後27709〜31426。
ゲーム内実測ではなくモデル内の比較。全ての敵・装備で必ずロンドが勝つとは主張しない。

ロンド後の攻撃直前に、攻撃1段階・会心率2段階・会心ダメージ1段階・限界突破を確認。
次行動者が別キャラなら会心補助はそのキャラに渡ることも検証。

所持品を勇者のつるぎ3本・月輪1本・ケキ1本に限定した実際の編成探索でも、
月輪＋継承ケキのロンドから攻撃する候補が首位になった（魔人Lv80のみ使用可能、検証用敵）。
探索1600件・装備4000件の上限内で実行し、所持数を満たすことを確認。

新規6件を含む計530件の回帰試験を確認。全体実行中にサーバー試験が
127.0.0.1への接続権限で失敗したため、その3件を追加権限で再実行して成功。
停止後の呪文・補助・画面・白こころ試験も個別に実行し成功した。

既存の固定探索テストは、追加した行動順から487731より高い544004の候補を見つけた。
最良値を旧探索結果に固定するテストから、既存候補以上を保ち、再計算・所持数・MP・討伐条件が一致する検証へ修正。
