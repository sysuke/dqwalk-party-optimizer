# 領域と補助の兼任・後段の待機再検査（2026-11-09）

## 原因

全体点検の呪文2ターンケースは、固定参考265,328に対して探索257,230。最良案では1個のどんぶりキングを主力へ配分し、領域担当が特盛一丁を使えなくなっていた。領域・ロンド・祈りを1役ずつ選ぶだけでは、領域担当が補助も兼任する組み合わせを取りこぼす。

さらに、通常の補助完成処理の後に役割編成を追加するため、新たな最良案の待機を再検査できていなかった。長期戦は最後の再検査があるが、2ターン戦にはなかった。

## 変更

- 役割候補に「領域と適応型補助を同じ人が担当、別の人がロンド、残る人が祈り/アンコール」を追加。役割内の `+` は兼任必須、配列の別項目は代替という扱いにする。
- 共有装備の修復では、領域色と補助スキルの両方を保護。主力の能力値用に装備した補助こころが競合する場合は、その余分な装備を外す。所持品を増やさず、修復後に能力・コスト・技能・在庫を再検査する。
- 兼任できない場合は従来の役割候補へ戻る。チーム候補数8、組立て確認128の上限を維持。
- 2ターンの火力比較でも、後段の候補生成後に残った評価枠で最良手順を見直す。最大32評価で、全体上限と締切は維持。再行動・自動攻撃のまとまりを壊さず、順序必須なら順序条件も維持。
- `shortPlanRefinement` に評価件数・改善前後・停止理由を記録。検証時は同名設定をfalseにして、最後の再検査だけを無効化できる。

兼任案では領域担当に補助こころを確保し、特盛一丁を主力へ適用。最後の再検査でおうえんも活用できる。計算式・倍率・敵耐性は変更していない。味方順はこのケースでは未成立であり、実行可能な推薦が完成したという意味ではない。

## 検証と残る課題

- 1個の補助こころが主力と競合しても兼任役へ残ること、在庫・コスト・役割が維持されること、元入力が変わらないことを検証。
- 兼任技能がない場合の通常役割への復帰も検証。
- 全体探索が固定参考を下回らないこと、再計算一致、特盛とおうえんの採用、32評価と全体上限の遵守を回帰検査。最後の再検査を無効にした同条件より改善することも検査。
- 評価枠や時間を使い切った場合は追加再検査できない。全ての攻撃スキル・編成・行動順の最適性は保証しない。
- 次は、速度条件を満たす案と必要な確率効果の少ない案を、強い固定手順との比較を保ちながら改善する。実測4件と敵ギミックの不足データは別課題として継続。

完了確認：715テスト（80ファイル）、配信参照150件が通過。実Chromiumの実Workerで同じ2ターン入力を計算し、397,890・988評価・特盛とおうえんの採用を確認。標準所持品の5ターン条件付き案も従来の3,945,368を維持した。6件の構造ベンチマークでダメージの低下はなく、速度必須の2件は順序成立を維持。
