# 通常9ターンの待機と、条件付き案の比較

## 報告の扱い

公開版851cad4の画像は、バハムート・ラムダ（零式）・火力比較・9ターン・通常条件、351,610ダメージ。以前の条件付き5ターン案とは入力条件が異なる。利用者の保存プロフィールは取得していないため、画像の結果そのものの再現とは扱わない。

「通常条件」はゾーン・暴走・AIの指定攻撃を仮定しない比較。確率効果を仮定しない下側の数値だけでは、実機で条件が揃ったときに参考になる攻略案を判断しにくい。通常時の探索漏れと、確率効果を使わないことによる差を分けて扱う。

## 修正

- 時空干渉を最終ターンだけに置く候補生成を変更。前半の2・3ターン、単独の2・3ターン、最終ターンを既存の評価予算内で比較する。
- 通常条件の長期手順では、待機を変更した後の最良手順を使って次の待機を検討する。前の変更でMPやバフが変わるため、同じ古い手順だけを参照しない。最大48評価かつ修正工程の30%以内で、全体予算は増やさない。
- 回数制限のある補助は、既に後半へ割り当てた行動を待機へ戻した上で前半へ移す案も比較する。2回使える技を3回使ったことにはしない。再行動と追撃の組は崩さない。
- 待機は防御効果を計算していないので「ぼうぎょ」と表示しない。「攻撃MP不足」「攻撃技なし」「代替案は未発見」を分け、展開すると残MP・最小攻撃消費と探索の限界を確認できる。MP不足はその時点の事実であり、以前の行動や装備を変えても待機が必須という意味ではない。
- 通常の火力結果から「成立条件を含む火力案も比較」を追加。所持品・敵・ターン数を維持して明示操作で比較し、直前の通常結果と並べる。元の通常条件へ戻して再計算できる。確率下限・こころ道・継承の許可は引き継ぐ。
- 比較には主力ゾーン・呪文暴走・AIが指定呪文を選ぶ条件を追加する。テンション100や未確認の発動率は追加しない。通常時の保証火力・期待値とは表示しない。
- 条件付き呪文準備案は、おうえんを使える職業が未育成でも、実際に持つ補助技で生成できるようにする。未育成職業や未所持品は追加しない。

## 固定手順の検証

`tests/fixtures/bahamut-turn-plans.json` の `standard9` は標準サンプル所持品、画像で確認できる職業・レベルだけを育成済みにした合成ケース。利用者の保存内容・実測値ではない。神鳥の翼斧の補助担当、どんぶりキング1個、時空干渉を9ターン目に置いた待機の多い手順を基準にする。

同じ装備・敵・9ターン・通常条件・修正150評価で、326,265から411,374、待機7回から1回。従来の凍結した手順を使う修正だけでは374,707。時空干渉は2・3ターンへ移り、空き行動を既存の攻撃へ戻す。MP・装備在庫・習得条件を戦闘全体の再計算で確認する。行動順未達の結果を先制成立には変更しない。

これは低火力問題全体の解決でも、通常条件で数百万を出せたという結果でもない。ゾーンなどの必要状態を減らす比較、MPを含む装備の再配分、敵の領域・ガード解除・ギガアタック、実機照合は引き続き課題。

実ブラウザとWorkerでも、標準サンプル・零式・通常9ターンの283,425から、明示ボタンで同じ戦力・敵・9ターンの条件付き4,109,157へ比較し、通常の283,425へ戻る操作を確認。条件付き案は972評価、確率null、テンション0。プロフィールを変更していないこと、ページ例外がないことも確認した。これは条件追加による別シナリオであり、通常火力の約14倍改善とは表現しない。

保存済みプロフィールの読み込み経路も、上記の画像で分かる職業だけを育成済みにした合成プロフィールで確認。通常388,096→条件付き3,434,384→通常388,096と戻り、保存JSON・敵・9ターンを維持した。おうえん担当を育成済みとして追加せずに成立する案で、利用者本人の所持品を再現したものではない。
