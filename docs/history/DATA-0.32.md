# 0.32 属性こころ追加・黒枠補正

確認日：2026-10-23。リュウちゃん通常Sと覚醒S、魔王ウルノーガSを追加した。各8能力・色・コストを収録し、各1個を比較用の初期所持数とする。既存の所持0や登録レベルを上書きしない。

リュウちゃん（覚醒）は白・コスト161、最大コスト+10、全属性ダメージ20%。全属性補正は無属性には加算しない。通常と覚醒の同時装備は禁止。回復技や耐性は未対応部分を残す。

ウルノーガは黒・コスト181・最大コスト加算なし。斬体11%、ドルマ斬体11%、デイン斬体-11%を収録した。会心率を確定会心へ変換しない。属性補正の合計が負の場合も物理式へ渡せるようにし、-100%未満の入力は拒否する。

## 黒枠の修正

旧データのnoColorBonusを全枠で適用していたが、公式の2026/1/1追記では黒スロットのみ色合わせが発生する。黒を含む枠は特級職の1.3倍、虹枠や他色枠は1倍とする。最大コスト加算なしは維持。装備計算・候補評価・旧solverで同じ条件を使用する。通常色の端数処理は今回変更していない。

0.25固定例は、魔人の赤黒枠にキラーマジンガがある。ちから寄与206→267で攻撃61増加、同じ入力の合計484,013→487,731。全576順序の最小ダメージ413,672→417,390となるが、失敗96ケースは残る。黒枠修正だけで安定討伐とは判定しない。過去の監査文書の数値は当時のモデルとして保持する。

追加こころによる候補絞り込みの変化に備え、従来の取りこぼし対策へ今回の新規3IDも含めた。討伐候補が見つからない場合だけ、0.31以降の追加こころを使わない条件でも再比較する。大域最適性は保証しない。
