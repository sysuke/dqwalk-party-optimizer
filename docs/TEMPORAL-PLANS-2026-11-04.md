# 準備ターンと短期の再行動

## 変更

複合手順の追加比較で、次の候補も扱う。

- 1ターンでも、習得済みのアンコールを使える味方がいる場合は主力の準備技を候補にする。準備→アンコール→主力の追加攻撃を、行動数・MP込みで計算する。主力の準備と補助1人の組合せも扱う。
- 主力の準備と補助を2ターン目、または終盤の残り2ターンへ移す案を追加する。もとの初手準備の案を残す。
- 準備より前は主力・攻撃補助を待機させるが、元の回復行動は保持する。いきなりスキルや領域を後から再発動したことにはしない。
- 真魔解放を使った直後の自動攻撃は既存の戦闘エンジンで処理する。効果中の後続ターンに命令できない待機が残る場合は指定呪文を選ぶAI比較とし、呪文MPを通常通り支払う。命令可能や無料詠唱に変える処理ではない。

時刻を変える候補は上位2つの複合案に限定し、総評価件数・締切は既存の追加探索枠内。全準備ターン・全攻撃回数の網羅ではない。初手から攻撃する従来案を保持し、新たな案も同じ戦闘計算で比較する。

`temporalPlans:false` で前段階の比較へ戻せる。`strategyTeams.temporalCalls` は準備を後ろへ移した候補の評価回数で、1ターンの準備案は `macroCalls` に含む。

## 構造ケース

`npm run benchmark:temporal` で、同じ192件上限で比較できる。仮の基礎能力・合成したシールド閾値・AIの指定呪文選択を明示した構造検証であり、実機のダメージや成立率の再現ではない。

### 1ターン

通常攻撃スキルを2回使う案は最大3枚同時ブレイク。きあいため→アンコールの追加攻撃を比較すると4枚同時ブレイクへ到達した。総ダメージ自体は同じで、主力の消費MPは少なくなる。シールド4枚と討伐成功は別判定のまま。

### 9ターン

初手から攻撃を続ける呪文案はMP不足で、この比較経路には資源条件を満たす主力呪文案がなかった。8ターン目に準備し、9ターン目まで攻撃・アンコールする案は所持数・MPを満たし、全9ターンを再計算できた。

このケースでは物理案の総火力が引き続き上位で、全体最良火力が向上したわけではない。別の攻撃スキルを使う有効な候補を増やしたことと、全体順位の改善を混同しない。

回復を序盤から継続するケースでも、準備を遅らせた際に回復を消さず、真魔解放後の通常行動の呪文MPを支払うことを確認する。

## 残る制限

命中・未知の発動率・実ゲームの速度乱数・未対応ギミックの保証はない。耐久目標では通常の被ダメージ・HP検査を通し、終盤まで待てることを無条件で仮定しない。仮シールドの判定は暫定のまま。通常探索全体での参考編成品質向上と、準備後の速度再調整は継続課題。
