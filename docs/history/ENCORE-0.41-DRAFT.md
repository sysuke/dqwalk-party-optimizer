# アンコールの準備行動と集中補助

2026-10-26。

## 修正した探索の不足

- FocusSearchと補助装備入れ替え探索はアンコール直後を攻撃にほぼ固定していた。きあいため・ゾーン付きため・呪文ため・確定会心準備・会心補助も追加行動の候補にした。
- 主力が習得した根絶やし付き全身全霊斬りを基本候補にし、2ターン目は通常技へ戻す。戦闘中1回の制限を維持する。
- アンコール役を先に動かし、準備→他の補助→主力攻撃が成立する順を追加。
- アームライオンSのきあいためを接続。根絶やしを使える魔人＋勇者のつるぎは、このこころでためを習得する装備候補も残す。所持数・コスト・最低HP/速度条件は緩和しない。

## 検証

追加行動で通常きあいため→特盛一丁→月輪継承ロンド→根絶やし付き攻撃を実行し、
攻撃3段階、会心ダメージ1段階、ため2倍、系統特殊効果への300%増幅が同じ攻撃に入ることを確認。
特盛は物理なら攻撃力2段階であり、おうえんのスキルダメージ80%とは別。
この連携自体はスキルダメージ80%を付与しない。

通常のきあいためを追加行動で使うと、勇者のつるぎの初手会心必中の行動回数は消費する。
その後の会心は別途条件が必要。テストでは会心を勝手に確定扱いにしていない。
3件の新規回帰テストで状態の引き継ぎ・探索候補の生成・根絶やし再使用禁止を確認。

弱い攻撃を禁止する固定ルールは追加していない。補助と攻撃を合わせた手順が実際に有利なら、
比較候補として成立するようにする修正。全コンテンツで同じ操作を強制しない。

## 未対応・未達

アギロゴスのシールドは一般の03探索では未再現。最大HPの10%分しかHPを減らさない攻撃でも、
素のダメージによる複数シールドの破壊判定が別途必要。
4枚同時破壊と2ターン討伐を、通常の総ダメージだけで保証しない。
100万超の実機一致・盾4枚破壊の保証は未達。
八重霞900を選んだ実際の編成・入力設定そのものは未取得なので、その結果を再計算して比較したとは扱わない。
