# 実測照合の補完（ローカル作業版）

2026-10-26。実測から係数を合わせず、出典で確認した入力の接続を修正。

## 修正済み

- 天超えし竜牙10%／会心5%の心珠を選択可能にした。2個で固有技20%と会心10%。他スキルへ固有技補正を流用しない。
- 固有技補正はテンション・ゾーンで増幅しない。心珠の会心補正は一般の特殊効果として増幅する。
- 大太刀・桃源郷の能力値と継承を追加。錬度4の攻撃12は得意条件付き。錬度10は斬体7%。陶酔を伴う攻撃手順は未対応と表示する。
- 実機攻撃力の指定は装備・継承込みの最終値として扱い、能力値を二重加算しない。
- 個人補正に戦闘中レベル上昇を追加し、物理式のlevelUpへ接続。時間レベルの自動抽選や呪文への能力値補正は未対応。
- 凍結0/1/2を敵条件で選択可能。被ダメージ倍率1/1.10/1.15として物理・呪文へ接続。守備力を変更しない。即死・速度・持続の再現は含まない。
- ユグノアのかぶと、世界樹の鎧下【滅】の火力特殊効果を追加。晴れ条件を分離。0凸守備力は未確認なので推測で登録しない。
- 蒼き竜王（覚醒）の8能力・黄・コスト183、斬体12%・全属性12%・ドルマ斬体12%・会心12%を追加。
- 世界樹の鎧下【滅】とオルゴ覚醒のユーザー確認を魔人の実測3件に反映。

## 検証と限界

7件の新規回帰チェックで、心珠のスキル限定・ゾーン増幅の区別・継承の条件・表示攻撃力・レベル補正・凍結・晴れ条件を検証。
既存回帰を含む524件が成功。これらは実機4件のダメージ一致を意味しない。

未収録アクセサリー、こころ道の具体的選択、敵守備力・固有耐性、
グレイナル固有の会心ガード軽減率は引き続き必要。
凍結と他の被ダメージ補正の合成・丸め位置は実測照合待ち。
通常・超越領域の実測表記は確度を分けて保存する。
