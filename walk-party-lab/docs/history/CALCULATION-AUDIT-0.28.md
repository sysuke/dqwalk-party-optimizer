# 0.28 全行動順の戦闘条件

全順序の討伐検証に、敵への先行、生存の入力有無、全員生存、キャラ別の終了時残HP・残MPの最小値を追加した。最小ダメージのケースだけを資源の最悪ケースとはみなさない。各キャラの最小値は異なる順序で発生し得る。

未検証の順序、評価例外、未登録の被ダメージを、生存確認済みとして扱わない。全順序の入力モデル条件達成は、全ケースの討伐・資源充足・先行・生存と特殊ギミック対象外が揃う場合に限る。既存の固定順判定は変更しない。

ダメージ式・敵ステータス・装備数値に変更はない。速度は利用者の指定区間、敵行動は1ターン1回の全員への固定上限モデル。状態異常、敵の複数行動、実機再現、全順序をまたいだ連戦の保証は含まない。入力が正しい場合の条件付き結果である。
