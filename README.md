# ウォーク編成ラボ

所持品・職業レベルと敵条件から、装備、補助、行動順を比較するブラウザアプリです。入力条件と収録モデルによる概算であり、実機との完全一致は未確認です。

## コードの構成

- `dist/data/` — コンテンツ、プロフィール、装備・こころ・スキル、検証記録
- `dist/domain/damage/` — ダメージ式と補正
- `dist/domain/battle/` — スキル順、ターン進行、HP・MPの計算
- `dist/domain/optimization/` — 装備・編成・速度・全順序の探索
- `dist/ui/` — 画面とブラウザ保存
- `dist/workers/` — バックグラウンド計算の入口
- `dist/styles/` — 画面のスタイル
- `dist/legacy/` — 現行画面から読み込まない旧実装。旧モデルの回帰テスト用に保持
- `tests/` — 回帰テストと固定入力
- `scripts/` — テスト実行と読み込み順の管理
- `docs/` — 構造の説明、計算監査と変更履歴

## 開発コマンド

外部パッケージのインストールは不要です。Node.js 18以上で実行します。

```sh
node scripts/test.cjs
node scripts/sync-entrypoints.cjs
```

`npm test` と `npm run check:entrypoints` でも同じ検査を実行できます。

ファイル追加・削除で読み込み順を変える場合は `scripts/entrypoints.cjs` を編集し、次を実行してHTMLとWorkerへ反映します。

```sh
node scripts/sync-entrypoints.cjs --write
node scripts/test.cjs
```

静的公開の入口は `dist/index.html`、配信設定は `.openai/hosting.json` です。バンドルやビルドは不要です。
