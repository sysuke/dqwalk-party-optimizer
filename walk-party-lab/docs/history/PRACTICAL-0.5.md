# アギロゴス実戦検証 0.5

公開サイトの「04 アギロゴス実戦検証」を開きます。

## 今回反映した条件

記事本文だけでなく掲載画像の操作表・編成表を確認しました。記事の画像どおりのプリセットが初期選択です。

- 並び：大神官 → 魔人 → 守り人 → 大魔道士（速度順とは別）。
- 大神官：はてんの月輪＋ケキちゃん継承。右隣の魔人が相棒。
- 魔人：勇者のつるぎ＋左手ロトのつるぎ改3。
- 守り人：ラッキーフォーチュン。左隣の魔人に行動開始時の良い効果延長。主人公に割り当て。
- 大魔道士：ロトの竜剣＋是空天ミカヅチ（覚醒）のこころで時荒らし。

1T：におうだち、魔人へバイシオン、風斬りのロンド、勇者の軌跡→根絶やし→選択技「全身全霊斬り」。
2T：魔人へおうえん、時荒らし、大魔道士へアンコール、再度時荒らし、魔人の全身全霊斬り。魔人の2Tの「オート」は、この検証では全身全霊斬りに固定します。

## 計算する部分

取得元・所持数・育成職の割り当て・継承条件・二刀流との排他・こころ道・MP・回数制限・追加行動・再行動・一部の補助状態・時荒らしの着弾後の効果短縮・シールド破壊とHP反映上限を処理します。割合MPは端数切り上げ、開幕消費やMP回復等は未計算です。

シールドは敵最大HPを基準に約24万/48万/72万/120万。残HPと別に管理。破壊は上限カット前の一攻撃単位のダメージで判定します。

記事再現の味方速度条件は守り人→大神官、大魔道士→大神官、大神官→魔人。守り人と大魔道士の相互順は成功の必須条件にしません。乱数モデルの1〜1.2倍は仮定で、敵の割り込みは保証しません。

## まだ完成していない部分

装備全体とこころ4枠を含めた厳密な火力自動最適化、根絶やし・二刀流・領域・会心・テンションを完全に組み合わせたダメージ式、敵行動分岐と生存判定は未完成です。記事の画像は防具等の名前と表示攻撃力を全て確定できる資料ではないため、数値を捏造して討伐成功にはしません。

今の0.5は、実用精度に向けたルール検証版です。アギロゴスは以前の一律攻撃の概算探索を止め、未確定のダメージを明示します。実測ダメージの入力は回帰照合用であり、最終的な自動選定の代わりではありません。手順や能力条件変更時は実測入力をクリアします。
