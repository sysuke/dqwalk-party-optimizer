# ロンドの重ねがけと残り0の消失時点

## 原因と確認した仕様

ロンドを2ターン続けても暴走率・暴走ダメージが1段階に戻る報告。通常の持続バフを、残り0になった本人の行動終了時に消していたことが原因だった。表示だけでなく、重ねがけ前の段階も失われていた。

仕様は「行動終了で残りを減らし、0の効果は次の本人行動開始時に消す」。残り0でも、次の行動開始前なら重ねがけ・延長ができる。ロンド自体の持続を2ターンへ増やす修正ではない。

確認資料（2026-11-09取得）：

- [補助効果の有効ターン数と重ね掛け](https://9db.jp/dqwalk/data/12222)：効果は適用後の指定回数+1回目の行動開始時に消失。重ねがけは最初の有効期間へリセット。
- [ケキちゃんの活用例](https://9db.jp/dqwalk/data/15320)：持続1ターンでも、攻撃役より先にかけ続ければ重ねがけ可能。
- [ケキちゃん](https://9db.jp/dqwalk/data/15208)：暴走率1段階+20ポイント、暴走ダメージ1段階1.4倍／2段階1.8倍。
- [延長効果の活用例](https://9db.jp/dqwalk/data/14400)：延長の発動タイミングと、通常の持続+1が上限であること。

## 修正

通常の持続効果を残り0で保持し、次の本人行動の直前に消す。ロンドが先行すれば、残り0の既存段階に加算して最大2段階となる。残り0で時空干渉を受けた場合も、保持中の効果を延長できる。

おうえんの1行動効果や確定会心などの回数制は別処理を維持。真魔解放・魔響の詠唱と直後のAI攻撃は、従来どおり合わせて1行動として持続を消費する。回数制限のある補助を使い直せるようにはしない。

バフ表示に「残0回・次の行動開始で終了」を追加。ロンドの説明に実際の段階を記録し、詠唱ごとの内訳にも「暴走ダメージ強化×1.8」などの補正を表示する。暴走の発動確率と暴走時の倍率は別に扱う。

## 待機中の補助比較

条件付き火力案では待機を埋める追加比較が無効だったため、有効化した。ダメージが大きいターンの待機を先に検討し、未使用の補助を入れるほか、1回限定のおうえん・特盛などを別のターンへ移す案も比較する。補助でロンドの次行動者が変わらないよう、並び順の変更もまとめて検証する。

最大48件（150評価の枠では45件）の追加比較を既存の長期修正予算内で使い、全体の件数・期限・使用回数・MP・所持数・解放条件を守る。待機理由には、その時点のおうえん・特盛・祈り等の残り使用回数も表示する。未使用でも後の攻撃のために残す場合があり、すべての待機が不要と判定するものではない。

正しい持続処理を使った固定ケースでは、おうえんの4→5ターン目への移動等により、旧補修2,781,668に対して新補修3,271,257（同じ150評価上限）。未使用ケースでは両者3,025,314に到達し、新処理は148評価、従来150評価。これは同じ修正後モデル内の探索比較であり、実測や利用者の保存内容の再現ではない。

## 検証と制限

- 物理・呪文ともロンド連続使用で1→2→2段階。更新しない次の行動では消失。
- 残り0での延長、更新後の倍率1.8、残り0の表示を確認。
- 補助の回数制限・資源・入力不変性・期限・評価上限を確認。
- 固定参考手順も新しい持続処理で再計算。自動探索が参考手順を上回ったため、参考値への完全一致を要求する旧テストは「参考値以上・再計算一致」へ修正。
- 全710テスト（80ファイル）通過。実Chromium・Workerでも2段階と×1.8、残り0の表示を確認。

既存の検証資料にある火力比較は修正前モデルの結果。今回の数値変化には持続処理の訂正も含まれるため、すべてを探索効率の改善とは表現しない。実機ダメージ・速度乱数・敵の特殊ギミックとの照合、探索の最適性は未確認のまま。
