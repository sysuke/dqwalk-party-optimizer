# 計算過程の追跡 0.51

2026-10-27。実測と異なる原因を調べるための機能。ダメージの倍率や敵の数値は変更しない。

## 使い方

1. 「個別検証ツール」の「装備とスキル順で検証」で実機と同じ装備・バフ・敵条件を入力し、計算する。
2. 「実測ダメージと照合・記録」で対応する攻撃を選び、表示値を保存する。
3. 記録内の「物理1発の計算過程と装備を確認」を開く。

補正後攻撃力・守備力、属性や斬体/補助の各倍率、会心倍率、基礎乱数値、乗算後の切捨て、固有スキル/ための切捨て、二刀補正後の切上げを表示する。最初の1発とため消費後の2発目以降を分ける。同じPhysicalCalculatorを呼び出し、説明用の別式は作らない。

装備・こころ・ボーナス一覧も照合記録へスナップショット保存する。後から画面上の装備を変更しても過去の記録を書き換えない。古い記録は現在の式で再計算すると、現在のカタログに基づく内訳を確認できる。

## 範囲と制約

この内訳は会心ガード・シールド適用前の物理1発。行動合計、ランダム追撃、複数敵、呪文の詠唱合計を再構成した値ではない。会心ガード軽減率不明を0と断定せず、0.50の照合保留を維持する。

実測551・6,055・43,197・67,674の再現完了ではない。敵の固有強化/軽減、こころ道の詳細などが未確定。[追加測定の優先順](MEASUREMENT-0.50.md)と[残課題](REMAINING.md)を参照する。

一般の会心を直撃と同一視して守備力を0にはしない。既存モデルは会心と直撃を独立に指定し、今回も維持する。
参照：[会心の公開検証](https://9db.jp/dqwalk/data/6582)、[直撃の説明](https://9db.jp/dqwalk/data/8232?p=2)、[計算式の実装参照元](https://github.com/AruDqw/dqw-damege-calc)。
