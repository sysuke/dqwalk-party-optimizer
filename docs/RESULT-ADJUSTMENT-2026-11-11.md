# 候補ごとの調整と行動順の説明（2026-11-11）

## 全体点検で見つかった問題

探索は複数の攻撃スキルと順序優先の別案を表示するが、簡易編集と主力固定は常に第1候補を参照していた。別候補を確認しても、その編成を起点に調整する入口がない。さらに、主力固定・武器除外のフォームが結果より前に置かれ、何をもとに探すのか分かりづらかった。

速度調整の詳細は個別検証側にあり、通常の結果は「すばやさの調整が必要」と表示するだけだった。全ターンの順序が矛盾する場合でも、装備を速くすれば解決できるように見えてしまう。

## 改善

- 結果冒頭で候補の攻撃スキル・ダメージ・順序成立を比較し、「詳しく見る」から該当候補を開く。
- 各候補に「この候補の装備・条件を調整」を追加。選ぶと対応した編集画面へ移動する。
- 簡易編集のキャラ・職業レベルと使用武器、主力固定・武器除外は選択した候補を参照する。調整対象の候補番号と攻撃スキル名を表示する。
- 登録内容を保存して変更する操作と、所持品を変更せず今回だけ固定・除外する操作を近くに配置。後者は結果より後に移す。
- 新しい探索結果を受け取ったら調整対象を第1候補へ戻す。古い候補番号を新しい結果へ持ち越さない。手順だけを再計算した場合は、その候補の選択を維持する。
- 順序未成立の候補には「この順番で動くために必要な調整」を追加。既存の速度制約解析を使用し、同時成立が難しい場合は手順の変更が必要なこと、成立可能なら表示すばやさの調整目標を表示する。敵への先制とは分けて説明する。

保存形式・所持品の初期値・戦闘計算・探索順位・評価上限は変更しない。この変更だけで順序成立や実機再現が完成したという意味ではない。

- 候補2を選択し、主力固定の送信内容がその候補の武器（月輪）になることを確認。第1候補の武器（銃剣）を使わない。
- 固定・除外ではプロフィール保存を呼ばない。
- 候補3を選択し、対応するキャラ・職業のレベルだけを保存して再計算することを確認。在庫は維持。
- 再探索結果の受信後に調整対象が第1候補へ戻ることを確認。
- 順序が矛盾する実例で、手順変更の説明を表示することを確認。
- 幅390pxで横方向のはみ出しがないことを確認。

## 継続課題

1. 火力を維持した順序成立案の探索。2ターン案は改善した火力があっても、順序が未成立のケースが残る。
2. 主力や候補の変更後、必要な確率条件を減らす別案の比較。
3. 選んだ編成の防具・こころを直接入れ替える編集。現状は所持数、レベル、固定・除外から再探索する。
4. 実測4件、敵ギミック、職業基礎能力の不足を、探索誤差と切り分けて継続調査。
