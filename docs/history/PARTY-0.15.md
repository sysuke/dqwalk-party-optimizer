# 周回資源検証 0.15

0.14の複数敵・手順編集に加え、周回方針にHP・MPの持ち越し検証を接続しました。

## 操作

1. 02で所持品、職業レベル、必要に応じて職業の実測能力を登録します。
2. 01で攻略先と「安定周回を目指す」を選び、探索画面へ進みます。以前の保存条件があっても01の攻略方針を反映します。
3. 08で敵1〜4体のHP・属性を確認します。敵速度と被ダメージが不明なら空欄にしてください。
4. 「属性・最低能力・解放条件」で比較する戦闘数を1〜100戦から指定します。初期値は20戦です。
5. 算出すると、攻撃役・武器・スキルの異なる候補も残し、最大48候補の中で連戦数を比較します。各戦の残HP・MPと回復量、停止理由を確認できます。
6. 「この手順を調整して再計算」でスキルや対象を変更すると、連戦も再計算します。結果JSONにも含まれます。

## 今回の計算

- HP・MPを次の戦闘へ引き継ぎます。毎戦満タンへ戻しません。
- 開幕スキルは毎戦消費します。割合消費は残MPではなく最大MPを基準にします。
- 戦闘ごとのバフとスキル使用回数をリセットし、同じ手動手順を繰り返します。
- 収録したこころの固定回復を加算します。エスターク覚醒はHP30・MP15、かみさま覚醒はHP77、是空天ミカヅチはMP5です。
- 固定回復は自身の通常行動の直前に1回とする保守的なモデルです。追加行動での回復を重ねず、死亡者を回復で復活させません。最大値を超えた分も計上しません。
- 固定回復を反映しない条件とも比較できます。
- MP不足・戦闘不能・指定ターンの火力不足が発生した戦闘で止めます。停止した戦闘は討伐数へ加算しません。
- 敵速度不明・被ダメージ既知なら敵が先行する保守的な条件にします。速度が未確認なら先制条件成立とは表示しません。

## 判断の限界

被ダメージ未登録ならHP推移は未判定です。何戦まで計算できたかは、入力した敵と手動手順、収録した回復の条件内での結果です。全出現パターンや自動操作のAIを保証しません。

壺・歩行・戦闘間の回復、ほこら等での回復ルール、回復呪文・回復武器の未収録効果、敵の行動パターンや状態異常の全分岐は含めません。こころの固定回復以外を一律に回復量へ足す処理はしていません。回復発動タイミングの全スキル・追加行動との組合せは実機照合が残ります。

敵1〜4体の通常戦・最大2ターンと、既存のアギロゴス専用検証が現在の範囲です。探索は候補を絞る方式で、大域最適や全ゲーム仕様の再現を意味しません。0.14の使い方と制約も適用されます。
