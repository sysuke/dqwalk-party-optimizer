# 補助持続と魔人こころ道（0.23）

## 変更

- バイキルトを汎用攻撃力アップの4行動モデルとして計算。これはコープスなど全ての開幕スキルの持続を4へ変更するものではありません。
- 攻撃・会心強化等の同アイコン再付与では、最初に付いた持続時間へリセット。会心のひらめきの後にロンドを使って持続を1へ縮める処理を修正しました。
- 魔人のLv20・Lv40こころ道をキャラ別に指定可能。未指定／超人道15%／超魔道25%を分離し、必要レベルと職業を検査。超魔道の斬体1%、Lv20のちから15、Lv40のHP/MPも反映。
- 基礎能力の実測登録はこころ道込みの値なので、その場合はちから・HP/MPを再加算しません。表示攻撃力の直接上書きにも再加算しません。
- こころ道の熟練度追加能力、枝のこころ条件の自動検査、確率マインドの自動成功は未対応。会心補正は会心倍率への加算であり、全ダメージを一律1.25倍にはしません。

## 比較結果

- 固定した等倍の比較モデル：追加会心補正なし43,096 → Lv20/40の超魔道を指定すると54,033（1発下限）。実機測定値ではありません。
- Dオルゴデミーラ強の既定条件は416,294で変わらず。魔人の両会心枝を超魔道、補助スキル解放済みと指定した条件では429,414。HP480,000には未到達です。
- コープスの開幕攻撃強化の持続は直接照合できていないため、既存の保守的な1行動条件を保持しました。
