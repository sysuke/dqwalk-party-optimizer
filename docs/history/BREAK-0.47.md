# 0.47 一撃4枚同時ブレイクを優先

03のアギロゴスに「一撃4枚ブレイク優先」を追加。既存の保存条件も初回だけこの目標へ切り替える。他の目標は引き続き選択可能。

順位は、使用可能な手順の4枚同時破壊を最優先とし、同時破壊枚数、一撃の不足、4枚破壊後の討伐と必要操作等を比較する。合計ダメージが大きくても、一度に必要量を出せない候補を優先しない。

判定用最大HPは残HPから分離。アギロゴスの目安240万に対し、10%・20%・30%・50%（24万・48万・72万・120万）を使用する。参照値のため編集可能。既存の専用検証と同じ閾値以上の判定を使用し、境界の実機の端数処理は未確認。同じ攻撃行動内の連続呪文・やまびこを合算する一方、アンコールの別行動は合算しない。

攻撃前のシールド段階に応じたダメージ上限を適用し、HPの残量を追う。4枚同時破壊した攻撃でも、未破壊からならHPへの反映上限は最大HPの10%。その後の攻撃でとどめが必要。累計4枚と一撃4枚、破壊達成と討伐達成を別表示する。下限と上限側参考を区別。

対応は単体・アギロゴス型のシールド段階。敵の会心ガード、戦闘中の耐性バフ、オーロラブレスによる強化短縮や解除手順等の未入力・未対応分を自動補完したものではない。条件付きゾーン等の実現率も別表示。シールドのみのモデル判定を実機成功の保証には使わない。

参照：[公式登場告知](https://walk.dragonquest.jp/web/news/show/2026100810)、[みんドラ：HP・シールド基準・攻撃内合算](https://9db.jp/dqwalk/data/20410)。
