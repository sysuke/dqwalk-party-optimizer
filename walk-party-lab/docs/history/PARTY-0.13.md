# 統合編成・手順探索 0.13

## 使い方

1. 「02 戦力を記録する」で所持数と4人の職業レベルを登録する。
2. 同画面の「職業の実測能力」で、装備・こころ・心珠・一時バフを外した素の能力と、こころ基本コストを登録できる。永続・こころ道などを含む実測値を使う。キャラ・職業・登録レベルが一致するときだけ計算へ反映し、レベルが変わったら再登録する。
3. 「01」で敵1体のコンテンツと1〜2ターン方針を選び、探索ボタンから「08 編成と手順を一括算出」へ進む。複数敵や周回方針は従来の概算探索へ進む。「08」を直接開くこともできる。
4. 敵1体の残HP・守備・属性耐性を確認する。敵の実効行動速度上限と、全候補・全員に適用できる耐性込み被ダメージ上限は、確認できた場合だけ登録する。
5. 必要なこころ道・継承錬度を本当に満たしている場合だけ解放条件のチェックを有効にする。未確認のゾーンや根絶やしマインドは自動成功にしない。
6. 算出結果で4人の職業、配置、主武器・左手・継承、防具・アクセ・心珠・こころ4枠とコスト、1〜2ターンの操作、各攻撃のダメージ、HP/MP、行動順と必要すばやさを確認する。
7. 結果はJSONで保存できる。「04の検証へ保存」で編成と手順を引き継ぎ、個別に再計算できる。

アギロゴスの特殊シールド・解除は既存「06」「07」の専用検証を引き続き使用する。「08」で特殊ギミックを外して比較した場合は、その条件を結果へ明示する。

## 探索

4人それぞれの育成済み職業から候補を作り、所持品内の主武器0/4凸、魔人の左手0/4凸候補、条件を満たすケキちゃん継承、こころ4枠、防具・アクセ・心珠を比較する。職業ごとの得意武器を適用する。

4人で武器・継承元・こころ・防具等の在庫を共有する。単独の最大火力だけを残さず、希少な心珠を使わない構成や武器の異なる代替も残す。こころ同種・覚醒違いの重複、コスト超過、未育成職、使用不可スキルを除外する。職業レベルは勝手に補わない。

配置と領域を比較し、開幕速度から自然行動の名目順を作る。最大2ターンについて攻撃・補助の対象・アンコールと対象者の追加行動・勇者の軌跡からの再行動を探索する。2ターン目の速度は1ターン目の行動消費を反映して並べ直す。

段階探索で候補を絞るため、全組合せの最適性は保証しない。キャラごとの装備候補には上限を設け、手順も既定12,000評価まで。打ち切った場合は画面へ表示する。主武器、左手、スキル、継承などの全データを網羅しているわけではない。

## 状態持続・MP

- 状態の持続は本人の行動回数で消費し、アンコールによる追加行動も数える。2ターン目に開幕効果を再発動しない。
- アンコールの追加行動と、その味方が持つ通常行動を分離。根絶やし・おうえん・勇者の軌跡の戦闘中の回数制限を扱う。
- 相棒の攻撃・会心率・限界突破とロンド補助の1行動、ピオリムの持続、フォーチュン延長の3行動上限を追跡する。おうえんは延長しない。
- 13武器の開幕MPを出典照合。割合消費の丸めが未確認のため、切捨て〜切上げの範囲を示し、MP可否は大きい側で判定する。MP不足の開幕効果を無料で発動させない。
- 確認できていないコープス開幕攻撃・テンション等の持続は、統合探索では1行動の保守的な条件を使う。根絶やしは全身全霊斬りを選ぶ想定で、実機のAI選択は別途確認する。
- HP/MPの自動回復・軽減は成功判定へ加算しない。無補給MP目安には毎戦の開幕消費を含む。

## 速度・HPの判定

味方の最大/最小速度乱数比を入力し、先行者の実効速度が後続者×比率を上回るかを検査する。1.2は検証用の初期値であり、全コンテンツの公式乱数仕様ではない。未達なら十分条件に必要な速度と不足分を表示する。

敵の実効速度上限を登録した場合、その速度で味方より先に動く可能性がある位置へ敵行動を差し込む。HPが0になった後に味方を攻撃させない。討伐前の必要な操作だけで味方順と先制を評価する。

敵行動は1ターン1回・全員に入力上限のダメージというモデル。装備ごとの耐性から敵の実ダメージを算出するものではない。速度・被ダメージが未登録の場合は、生存や順番を保証した結果にしない。登録済みでも「入力モデル内」の条件成立と表示する。

## 残る対応範囲

全ボスの行動分岐・シールド・解除・状態異常、複数敵への攻撃分配、回復技、連携、未収録の職業固有効果・装備・こころ、こころ道解放用こころの消費、3ターン以上の探索は統合エンジンの対象外。敵と職業能力に仮値がある場合、実ゲームの討伐・安定周回を保証しない。

この版で「コンテンツ・方針と所持品・レベルの登録 → 4人の構成と手順 → 火力・資源・速度の条件確認 → 個別検証と結果保存」の操作を接続した。ゲーム全仕様の再現完了という意味ではない。
