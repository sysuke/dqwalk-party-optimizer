# 保存しないSHTガード比較（2026-11-13）

バハムートの現在の計算は、SHTガードの軽減率99%を全ターン固定で適用している。実際のガード解除後の火力を、この固定条件の結果だけと比べることはできない。

各候補へ「敵のSHTガード条件を変えて比べる」を追加。軽減率0〜100%を入力し、その候補の装備・手順・敵のその他条件・指定したゾーンや暴走を固定して再計算する。簡易な倍率割り戻しではなくPartyBattleを再実行し、各詠唱・シールド・MP・残HPを再評価する。

比較は保存しない。主結果・候補の順序・プロフィール・コンテンツ設定を書き換えず、元条件と変更後の火力、削るHPと残HPを併記する。元の順序別検証値は流用しない。テンション100の攻撃がない場合はガードを変えても増えないことを説明する。

0%は全ターンでガードがないという仮定。実際の解除タイミング・敵領域・ギガアタックは再現しない。ゾーン・テンション・暴走の成立率を増やす機能でもなく、平均火力・攻略成功を保証しない。SHTガード設定のある単体敵に限って提供する。

検証：同条件での直接再計算との一致、元入力不変、不正率の拒否、SHTなしでの不変を回帰検証。実Chromiumと実Workerでも保存設定と主結果を維持して比較できることを検査する。

次は、独立した敵行動の根拠をそろえて解除条件・時点をモデル化し、強い固定参考手順との同条件照合を進める。今回の仮定比較だけで実測火力との差が解消したとは扱わない。

全体725テスト（80ファイル）・配信参照150件が通過。実Worker比較で主結果・localStorage不変、幅390pxで横はみ出しがないことを確認。
