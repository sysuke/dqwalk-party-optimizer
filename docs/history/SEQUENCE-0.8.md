## 操作

1. 「04 装備とスキル順で検証」で4人の育成データ・職業・武器・こころを選ぶ。
2. 継承、左手、防具・心珠・得意武器・開幕効果を必要に応じて指定する。
3. 敵の系統、守備力、耐性、今回有効な領域を設定する。
4. 「装備から使えるスキルを更新」で候補を更新し、4人各1行動の順番と補助対象を指定して計算する。

初期例は「おうえん → バイシオン → 月輪に継承した風斬りのロンド → 勇者のつるぎの全身全霊斬り」。コープスの開幕攻撃2段階、相棒の攻撃上限3段階、ロンドの次行動者への会心補助、おうえんの威力80%加算、勇者の確定会心を状態として反映します。補助を外したり後ろに動かせば、先の攻撃には反映しません。

## 現在の限界

- 1ターン・4人各1行動の指定が対象。再行動・アンコール・複数ターンの自由な編集はまだありません。
- 職業の基礎能力、永続・熟練度等は仮値が残るため、装備から算出した攻撃力は参考値です。実機の装備込み表示攻撃力で上書き可能です。数値を入れず試せますが、それを正確な実機火力とは扱いません。
- ロンドは後続への補助を計算しますが、自身の攻魔複合ダメージは未算定。合計は「対応した攻撃の合計」であり、未算定分を含まないと明示します。
- 呪文・攻回複合・祖竜の固有ゾーンなど未対応のスキルを選ぶと計算を止めます。未収録効果を架空の値で補いません。
- 左手武器から使えるのは攻撃のみ。継承は確認したケキちゃんの風斬りのロンドを対象に、同種武器・錬度1以上・二刀との排他を確認します。錬度別の継承特殊効果は未対応です。
- MPは資料不一致があるため可否判定に使いません。勇者の軌跡には最大MP10%と固定66の資料差を記録しました。
- 職業の全装備適性、全特殊効果、命中・ガード・上限・敵行動・シールド・生存・速度乱数・4人共有の所持数は、この手動検証では完全な制約としていません。自動選定に進む前に検証・統合します。
