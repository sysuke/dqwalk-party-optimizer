# 0.43 補助集中候補の探索漏れを修正

- 装備を入れ替える補助探索を最大2人から3人まで拡張。アンコール・特盛・ロンドを同時に比較できる。
- 単独交換の全列挙で予算を消費する前に、3人・2人・1人の交換を交互に比較する。
- 補助編成の比較枠を探索予算の40%地点から55%地点まで拡張。最終順位は既存の実計算結果で決まり、補助スキルを使うだけで加点しない。
- アンコール後の準備スキルを攻撃技の先頭5件打ち切りから除外。こころから使えるきあいため等も候補に残す。
- 集中手順探索では、短いスキルダメージバフを1ターン目に使う候補も追加。

回帰検証：実在の装備・スキルと実際の戦闘計算を使い、補助3人の交換、アンコール準備、特盛、ロンドを含む候補が64評価以内に到達することと、補助を外した同じ構成よりダメージが増えることを確認。

職業とレベルを報告例に近づけた別途の統合探索でもロンドを含む編成を確認。ただし敵守備力・所持品等が報告例と同一ではなく、実機ダメージの一致や100万到達を証明するものではない。アギロゴスのシールドを含む特殊なHP推移も、汎用編成探索では依然として未対応。
