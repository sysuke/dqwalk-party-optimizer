# 0.45 最終候補の職業・こころ・手順を同時修正

0.44の職業再比較は行動列を維持していたため、待機役を守り人へ変更しても「おうえん」を発見できなかった。また、火力目標探索は装備を固定し、こころの交換とアンコール準備の変更を同時には検証していなかった。

最終候補に独立した比較枠を予約し、育成済みの守り人への変更とおうえん、所持するきあいため付きこころへの交換、アンコール準備、ロンドの直前配置を一組で再計算する。使用回数、MP、在庫、コスト、職業レベル、行動順は既存モデルで判定する。計測済み表示ステータスを持つ主力のこころは勝手に交換しない。

評価枠は全体上限内の最大192件。未育成職を付与せず、比較後の結果は通常の順位規則で選ぶ。100万等の目標に合わせて倍率を変更しない。

報告例のJSONを使い、536,896を一致再現。実際の所持品と職業レベルで、はめつのゴーレムと守り人を使う連携を直接比較したところ689,731に改善。内訳は1Tロンド826、根絶やし攻撃441,444、2Tロンド921、攻撃246,540。この数値はモデル上の比較で、実機測定やシールド込みの勝利確認ではない。個人のバックアップJSONはリポジトリに含めない。

同じバックアップから、装備も含めた通常の自動探索を実行（手順上限12,000・装備候補上限160,000・時間上限120秒）。最終結果1,010,789、評価10,851件。1Tロンド1,182、根絶やし攻撃697,888、2Tロンド1,323、攻撃310,396。入力HP120万には未到達。
