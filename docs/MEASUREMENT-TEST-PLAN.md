# 実機照合・不足データと追加測定

2026-10-26。対象は時空の歪みの黒き偽竜グレイナル。

## 現時点の判定

実測551と6055は保存済みだが、数式と実測の一致判定は未達。
会心ガード軽減率と敵守備力を独立に確定できていない。
現行の「0〜軽減前上限」に実測が入っても、精度検証に合格したことにはならない。
前回の517件の成功はソフトウェア回帰テストであり、この2件の実測一致ではない。

再現可能なカタログ照合：`node scripts/audit-measurements.cjs`。
完全一致で調べるため、別名・覚醒表記差は未登録と区別して確認する。

## 確認した不足

- 大太刀・桃源郷：継承武器カタログに未登録。錬度1/4を再現できない。
- 天超えし竜牙専用心珠：物理単発計算にはskillCorrection入力があるが、手順エンジンは専用心珠の20%をこの入力へ接続していない。
- 時間レベル1：単発計算のlevelUpへ手順エンジンから渡していない。
- 1件目のバトルマスターの極意書・ほしふるうでわは完全一致の登録なし。
- 2件目のユグノアのかぶと・世界珠の鎧下・はぐめたのお守り・スラいいねの勲章＋は完全一致の登録なし。
- 闇の覇者 蒼き竜王（覚醒）は完全一致なし。天魔王オルゴ・デミーラは覚醒版があり、ユーザーの覚醒表記省略か通常版か確認が必要。
- 地獄の帝王エスタークは「（覚醒）」付き登録がある。未登録と即断せず、実機の種類を確認する。
- こころ道「だいたい超魔道」では会心加算などのノードを一意に決められない。
- 他3人のゾーン・発動職業が不明。自分以外の職業ボーナスも影響し得る。

表示攻撃力1514/1796を指定する照合では、防具・こころ・両手持ちの能力値を再加算しない。
ただし特殊効果の斬撃・属性・系統・会心補正は、表示攻撃力では代用できない。
ゾーンの会心加算230%と会心ダメージ1段階の乗算1.4倍は、現行コードで別枠。
ゾーン中の特殊効果強化とテンションは高い側を適用する現行処理であり、二重増幅していない。
これらはコード確認であり、実機での総合検証済みを意味しない。

## 追加測定の前に必要な情報

2件目の装備を変える必要はない。こころ道の各ノード、こころの覚醒・ランク、
他3人の職業とゾーン有無を記録する。攻撃直前の画面があれば有用。
「極限集中」を直前に使っていたか、次の一撃2.25倍が残っていたかも確認する。
ゾーンだけから2.25倍を推定して付与しない。

## 最優先の実機テスト

### A. 同一条件のばらつき

2件目の構成とバフで、超会心の1発を目安5回記録する。
毎回、敵テンション4・会心ガード・追加の斬体軽減や属性見切りの有無を記録。
同じ戦闘の連続攻撃でも、バフ・こころ道の発動効果が変化したら別条件として扱う。
目的は6055が単発の乱数か、条件が継続的に同じかを確認すること。

### B. 会心ガードだけの差

可能なら、同じ超会心を「会心ガードあり／なし」で各3〜5回測る。
その際、敵テンション・守備段階・属性見切り・斬体軽減・自分と味方のバフを同一にする。
ターン経過で他の効果も切れた場合は比較用のペアとして使用しない。
難しければ無理に再現せず、攻撃直前の全状態を記録する。
目的は守備力と独立に会心ガードの軽減を絞ること。1発同士の比から断定しない。

### C. 心珠の接続確認

Aと同じ条件で、専用心珠2個を外した超会心を3〜5回測る。
代わりの心珠は装備せず、表示攻撃力も記録する。
この比較では固有技+20%と会心+10%が同時に変わるため、両方を含む予測差を検証する。
固有技補正だけの単独測定と扱わない。

## 記録テンプレート

戦闘場所／ターン／攻撃力／武器凸／こころ道／攻撃スキル／ダメージ1発／
会心表示／極限集中の残り／自分と他3人のゾーン職業／味方バフ／
敵テンション／会心ガード／斬体軽減／属性見切り／領域。

## 合格条件

独立した入力を埋め、同じ状態の実測が予測乱数範囲に入ることを確認する。
別条件でも同じ式を使用し、個別の実測に合わせた係数を追加しない。
未知の敵パラメータを推定する場合は、推定に使わなかった別測定で検証する。
