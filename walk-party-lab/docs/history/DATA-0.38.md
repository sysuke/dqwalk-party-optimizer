# 0.38 職業と装備・役割の再割り当て

2026-10-26。03「編成・結果」で、魔剣士が女神ペルセリアのつえ、大魔道士が祖竜【理】の銃剣を持つ結果への指摘を受けて調査。

## 確認した原因

候補段階では得意武器や職業ごとの能力・収録済み特性を参照していた。しかし単独の攻撃点と補助点で候補・チームを先に絞り、その後は主に行動順を探索していた。最終候補の職業と装備・手順を交換する比較が不足しており、同じ計算モデルでも劣る組み合わせを残していた。

職業基礎値が仮値であること、未収録の職業特性があることも引き続き制約。この修正だけでデータ・戦闘式が完全に正しいと確認できたわけではない。

## 再現した例

初期所持品・Lv80のいびつ世界の幻竜で、魔剣士＋ペルセリア／大魔道士＋補助武器が選ばれた。職業と育成キャラを維持して装備・役割を交換すると、同じ手順・同じモデルで159,453→177,733。別の時間制限到達時には、指摘と同じペルセリア／銃剣の組み合わせも再現し、交換で145,527→163,807となった。

修正後の2,500ノード上限の探索では265,296を記録し、大魔道士＋ペルセリアを選択。初期データ上の参考計算であり、ユーザーの保存条件との完全一致や実機ダメージの確認ではない。実行負荷と時間制限によって近似探索の到達点は変化する。

## 修正

- 装備一式と、その装備を使う手順・補助対象を交換し、戦闘エンジンで再計算。
- 育成済みの別職へ変更した候補も再比較。キャラのレベル・こころ道・アンコール・根絶やし等の解放条件を変更先の条件で判定する。
- 得意武器フラグを変更先の職業と武器種から再計算。こころの枠色、職業能力、収録済み特性、装備制限、MP、所持数、速度条件を再検査。
- 手順を先に固めた最終候補に加え、探索の早い段階でも再比較を実行。上限の一部を共有し、追加探索によって全体ノード上限や既存の時間制限を増やさない。
- 入力した装備込みの実機攻撃力・攻魔を、違う装備や職業へそのまま流用しない。その条件の自動交換は省く。
- 結果に得意武器補正の有無・主な行動を表示し、攻撃用か補助・領域用かを判断しやすくした。探索状況には再比較件数を表示。

「魔剣士に杖を禁止」などの職業名による固定は行わない。補助・領域・収録済み職業特性によって非得意武器が有効な構成も残し、実計算で改善した候補を採用する。

## 残る制約

この再割り当ても予算内の近似探索。全職・全装備・全手順の大域最適は保証しない。新しい職業・装備に合わせた防具・こころの再最適化は既存候補生成の範囲で、交換後の全組合せを列挙してはいない。職業特性の確率・基礎能力・未確認の敵ギミックは別途整備を要する。

## 検証

全513件合格。報告された杖・銃剣の交換で実計算が改善すること、手順・対象の移動、育成レベル・解放・得意武器の判定、実機能力値の誤流用防止、予算共有を追加6件で検証。テスト件数は実機との一致例数ではない。
