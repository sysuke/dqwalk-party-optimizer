# 0.33 呪文データと開幕MPによる候補消失の修正

確認日：2026-10-23。職業の未登録基礎能力は引き続き仮値。

## 候補消失

詳細カタログに登録した武器と開幕MP表の対応がなく、PartyBattleが例外を投げて全手順を除外していた。ロトのつるぎ改3には開幕スキルがないため、開幕ONでも0MPと登録。一般の未確認MPも例外にせず、既知消費分のみ差し引いて火力比較を継続する。

MP未確認時は `mpKnown:false` と対象キャラ番号を返す。残MPは参考値、MP充足と連戦可能数は未判定、総合条件達成にしない。既知の開幕MPや行動MPが不足すれば従来どおり候補を除外。未知を0MPで確認済みと偽らない。

## 追加した詳細計算データ

- 武器6種：女神ペルセリアのつえ、とこしえの杖、パラドクスの杖、星海の天球儀、あまぐもの杖、ウロボロスのつえ。0/4凸能力、得意パッシブ、通常補正、MP、主要攻撃8種と破戒詠唱・刻。
- こころ10件：リーズレット、ワイトキング通常/覚醒、堕天使エルギオス、冥獣王ネルゲル、おどるほうせき通常/覚醒、にじくじゃく通常/覚醒、ベロニカとセーニャ。S全8能力、色・コスト・呪文/属性/系統補正。既存の仮データ2件は置換。冥獣王ネルゲルの固定HP20回復も接続。
- 防具9件：女神ペルセリア、ベロニカ、深紅シリーズ各3部位、最大Lv0凸。素の能力とパッシブを分離。ペルセリア冠の幻竜固有ダメージ10%は対象名一致時、晴れの全属性3%は天候指定時だけ適用。
- 新規品は比較用初期所持1個。保存した0個を上書きしない。4凸武器は初期0本。覚醒前後のこころを同一キャラに重複装備不可。

ペルセリア衣下の0凸守備力70のみ、掲載4凸92と同シリーズ頭の比較からの仮値として注記。火力に使う攻魔34と呪文/属性補正とは分離し、完全確認済みとは扱わない。

## 呪文モデル

`domain/damage/spell-calculator.js` に独立。公開検証の魔力上下限・基礎威力の端点間を線形補間し、上限を適用。呪文補正、属性補正、系統/固有敵補正、種別耐性、属性耐性、領域、テンション/ゾーン由来の既存補正、呪文威力段階、詠唱ためを計算。

- ラブ・ストリーム：魔力15→基礎211、1950→4315。敵1体のみ基礎威力3倍、ザバ/バギ/デインを個別計算して最も下限が高い属性を選ぶ。
- メラガイアー：10→600、2400→11000。攻撃時メラ耐性-50ポイント。とこしえ開幕の魔力かくせいは呪文威力2段階40%。
- 天才魔法使いのイオナズン：15→165、1800→2420。
- フォビドゥンバースト：10→100、2200→8000。
- フェイタル・ステラー：15→620、2450→10411。命中後に自身の呪文威力+1段階、次の攻撃から適用。
- ざざん波：15→300、1950→3600。
- メドローア：15→800、1800→6700。滅：15→281、1800→2340。
- 破戒詠唱・刻：最大MP10%、戦闘2回、次の攻撃呪文2.2倍。物理きあいためとは分離。

呪文用のこころ・防具は攻撃魔力を使って初期候補を作成し、実際の呪文計算で順位付け。装備最適化・手順探索・Workerの各経路で同じモデルを使用。ギガモンの初期方針は指定ターンの与ダメージ（討伐不要）。斬/体/呪文/ブレスの耐性を画面で別々に表示・保存。

## 限界

通常詠唱モデルであって、全効果込みの最大火力ではない。乱数±5%と丸めは実機照合待ち。暴走・超暴走・マナ・連続呪文・やまびこ・確率ゾーン・死亡再行動・馬車・職業特性の未対応部分は加算しない。あまぐもの開幕ON時は未算入の追撃消費があるためMP未判定にする。

幻竜は斬体/ブレス0.4倍、呪文0.7倍、バギ1.2倍など掲載倍率を使用。シールド・ミラージュフォーム・2Tいてつくはどう・他プレイヤー・ギガアタックは再現していない。表示の合計はシールド等を適用する前の個人火力比較。実機表示やランキング貢献を保証しない。
