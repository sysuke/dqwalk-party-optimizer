# 結果から敵条件を保存せず比較（2026-11-13）

SHTガードだけの試算を、単体敵の守備力・斬撃／体技／呪文耐性・各属性耐性へ拡張した。各候補の「敵の耐性・守備力を変えて比べる」で開く。耐性は通常は折り畳み、0%は等倍、正は耐性、負は弱点と説明する。

装備・手順・指定した確率状態・敵HPは固定する。PartyBattleで全手順を再実行し、各攻撃の属性選択・各詠唱・シールド・MP・残HPも再計算する。変更項目は元値→今回の値を列挙。新しい条件に最適な編成を再探索する機能ではない。

元の候補・設定・所持品を変更／保存しない。元の順序別検証を変更後の結果へコピーしない。SHTガード設定のない敵にも提供し、その場合はガード入力を出さない。種別耐性の一部だけを上書きした場合、他の種別は既存の共通耐性へフォールバックする。無属性に属性弱点を乗せる処理は追加しない。

複数敵は対象別の編集を混同しないため対象外。全ターン同じ敵条件の仮定であり、ガード解除時点・敵行動を再現せず、実戦火力や平均値の保証もしない。不正値・未対応項目は再計算前に拒否する。

以前のSHT専用画面と処理は統合し、同じ目的の入力欄と再計算処理を二重に残さない。

検証：変更後の直接再計算との一致、元入力不変、変更なしで元火力一致、種別ごとの独立上書き、不正入力・複数敵の拒否。実Chromiumと実Workerで守備力・SHTガード・呪文耐性を変更し、表示の再計算一致・保存内容不変・幅390pxでの操作を確認。

次は、実測・強い固定参考手順の条件不足を解消し、入力値の比較から実際の未対応効果の特定へ進める。変更後の高い火力を、実際にその敵条件が成立する証拠とは扱わない。
