# 未装備の所持品を含めた速度調整（2026-11-13）

## 変更

速度調整の別案比較を、装備中の品の移動・交換から、未装備の所持こころ・防具の追加・入れ替えへ拡張した。プロフィールの所持数や初期値は変更しない。

- 収録済みの速度付きこころ・確認済み防具について、所持数から4人の使用数を引き、余りがある品だけを候補にする。既に1個使っていても、2個持っていれば残り1個を比較できる。
- こころは4枠、防具は対応部位へ装備する。空き枠だけでなく入れ替えも比較し、技能・領域・色・コスト・重複系統・最低能力・在庫を再検査する。
- 追加した装備による能力・速度を再計算し、その状態で起こり得る全順序を検証してから案を採用する。未知のMPや未完了検証を下限の証明にしない。
- 装備込みの実測攻撃力・攻撃魔力を指定した編成は引き続き変更を見送る。必要なゾーン・暴走等の条件を勝手に減らしたり、発動確率を補ったりしない。
- 各組立て確認枠の最大1/4（最大64件）を未装備品へ割り当て、既存品の再配分と併せて比較する。初回は128件以内とし、2回の移動・交換の比較を含む全体256件以内に収める。
- 戦闘評価は既存の順序検証64枠と全体上限・締切を共用する。最良候補を置き換えず、条件の異なる別案として残す。

開発比較では `orderRangeUnused:false` で未装備品の比較だけを無効化できる。所持品を全列挙する探索ではなく、速度付きの候補を優先する近似探索。3回以上の変更や全所持品の最適性は保証しない。

## 構造検証

既存の速度装備検証プロフィールを使い、主力の `god` こころを外した状態から比較する。所持数は2個のままで、1個は領域・補助担当が装備、残り1個が未装備。実在カタログの能力値を使った検証用プロフィールで、ユーザーの所持品や実機測定ではない。

| 条件 | 順序別最低火力 |
| --- | ---: |
| 装備中の品の移動・交換だけ | 178,637 |
| 未装備品も比較 | 314,104 |
| 未装備こころ1個の追加先（4人×4枠）と準備有無の全列挙 | 314,104 |

未装備のこころをロンド担当へ付けることで、元の担当の速度装備を失わずに味方順を整えられた。比較45/48評価、組立て157/256件以内。新しい所持品の登録やダメージ倍率の変更はしていない。数値はシールド上限前の条件付きモデル値であり、実機の安定成功を意味しない。

## 検証方法

- `node tests/conditional-order.cjs`：未装備品を含む比較、同じ小規模条件の全列挙との一致、所持数・必要技能・領域・コスト・入力不変、未所持防具の除外を検査する。
- ブラウザ内でも実際の比較モジュールを実行し、178,637→314,104と予算・プロフィール不変を確認。
- 実Workerでは従来の速度配分ケースの結果を維持し、既存の別案表示へ支障がないことを確認する。これは上記の固定手順からの比較と分けた検証。

## 継続課題

探索が必要な確率状態を減らす案、未対応効果・職業基礎値・実機ダメージの照合を継続する。既存の強い参考案との比較を保ち、弱い下限の微増だけを推薦品質の基準にしない。

完了確認：719テスト（80ファイル）と配信参照150件が通過。ブラウザ内の比較で178,637→314,104、実Workerで既存ケースの結果維持を確認。既存6件の基準火力と速度必須2件の順序成立を維持した。
