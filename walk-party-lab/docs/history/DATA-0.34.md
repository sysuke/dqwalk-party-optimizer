# 0.34 職業特性と発動時比較

2026-10-23。ダーマの神杖（最大Lv・0/4凸能力、得意補正、大神官MP+10、祈り15%・2回制限、開幕MP23）を収録。

ダーマの祈りは対象の次の通常行動開始2回で連続呪文を成立させる。対象が行動済みなら遡及せず、次ターンから。通常延長の対象外。追加行動開始での祈り消費は未検証のため通常行動だけに限定する。他職の特性は未実装のため対象エラーとする。

連続呪文は2回の有料詠唱で、2回目のMP不足では1回だけになる。ためは最初の詠唱で消費。フェイタル・ステラーの呪文威力上昇は次の有料詠唱へ反映。斬体の+100%は一般威力加算群に加える。

個別検証では暴走・連続呪文・やまびこの発動確認条件を指定できる。自動編成にも「暴走＋大魔道士のやまびこ発動時」比較を追加。発動率を100%にする手順を自動で成立判定する機能ではなく、確率条件付きの火力として表示し、conditionsMetをfalseにする。

やまびこは大魔道士のみ、50%・追加MPなし。各有料詠唱に1回。ためを再適用しない保守的比較。暴走は公開検証の代表倍率1.75を使用し、会心ダメージアップとは別集計の呪文暴走ダメージ、ゾーン、ロンドの暴走ダメージ段階を反映する。暴走固有の実際の乱数分布・丸めは未照合なので厳密な実測下限ではない。超暴走・マナは未対応。

検索は祈り役を別枠に残し、補助役の装備差し替えと対象・手順を比較する近似探索。全列挙による最適解保証はない。複数敵への連続呪文の途中で敵が倒れる場合の対象再選択は未再現。職業基礎能力・特殊ギミックの既存制限を継承。
