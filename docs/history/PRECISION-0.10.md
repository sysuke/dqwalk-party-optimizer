# 0.10 火力と属性の点検

「04 装備とスキル順で検証」を更新。

- 根絶やし → 全身全霊斬りを追加。魔人・根絶やし解放済み・該当スキル習得を条件とし、系統特効の効果値に300%の増幅を加算。総ダメージを4倍にはしない。
- 勇者の軌跡の通常レインボーフォースと直後の再行動を追加。使用前の補助、会心必中の行動消費、隣接ラッキースティックの延長を追跡。根拠のない再行動は拒否。
- 通常フォースの属性ダメージ補正半減、敵耐性、領域、発動済みフォースブレイクを別の群として計算・表示。無属性に属性補正を加えない。
- 魔剣士の発動済みフォースチャージを属性と段階で指定可能。1段階30%、上限6段階。装備属性補正とは別に加算。
- 発動済み根絶やしマインドを通常60%／超魔道強化180%から選択。未確認時は加算しない。
- 装備・防具・心珠を入れた強化条件の例と、各属性候補・倍率内訳を追加。

## 10万と100万について

元の等倍初期設定は合計120,696〜136,881。防具・心珠が空で、根絶やし・勇者の軌跡も未使用だった。強化例は調停者3部位＋ガイア心珠2個＋勇者の軌跡→根絶やし→全身全霊斬りを指定し、280,781〜318,433となる。同じ等倍敵のままで100万になることは確認できていない。ゾーン、系統強化、弱点、実機攻撃力など実際の条件を確認して比較する必要がある。100万へ合わせる任意の補正は追加していない。

## 残る範囲

職業の素能力は従来の仮値。実機表示攻撃力で上書きできる。ロンド固有の丸めは未実測。今回の再行動は勇者の軌跡に限定し、アンコール・複数ターン・連携・敵行動・シールド・MP充足・生存・速度乱数・命中・ガード・上限の完全な戦闘再現は未完了。FB・FC・マインドの確率発動は自動成功にせず、開始時点で確認済みの状態を選択する。属性耐性アップなど選択肢にない効果の自動追跡、馬車・永続・職業固有効果の網羅も未完了。
