# 長期戦の小火力と補助手順の再比較

5/9ターンで小火力の八重霞が残り、補助より攻撃を続ける症状を調査した。火力比較で耐久を評価しない変更も保持する。

原因と変更：

- 長期戦で2ターン専用の処理を除外する際に、全ターン対応の補助役再探索まで止めていた。装備と職業を含めた補助・アンコールの比較を長期戦にも実行する。
- 旧初期手順はMPをターン数で割り、その枠に入る安い攻撃を並べていた。強い攻撃をMP内で複数回使う手順から比較する。足りない枠は待機とし、その後の補助探索・MP確認で埋める。攻撃回数を増やすためにMPを捏造しない。
- アンコールを毎ターン並べると長期戦では供給側のMPが不足し、補助案全体が落ちる。供給側の実MP・開幕消費に加え、主力の残MPに収まる回数も試す。3回が不足でも1回を落とさず、MP回復等が絡む場合に備えて供給側上限の案も残し、自己強化との組合せも同じ戦闘計算で比較する。
- バフ役→ロンド→主力→アンコール、またはアンコールで準備→バフ→ロンド→主力、という全手順も検証する。元の速度順も保持し、速度条件を必須とした場合は同じ検査で落とす。
- 最後の補助比較へ計画件数の一部（最大640件）と時間を確保する。総件数・総時間の上限を増やす変更ではない。
- 弱攻撃の抽出は主力の累計ではなく、最大1攻撃の15%を基準にする。9ターンになっただけで全サブ攻撃を弱いと判定しない。この率は候補抽出だけに使い、優劣は全ターンの再計算で決める。
- 連鎖するアンコール→オーバードライブ→次の行動を、途中で別の通常行動に分割しない。

八重霞自体は除外しない。追加ダメージや残MPの使い方として有利で、比較した合法な補助手順より良ければ残る。所持数、育成レベル、使用回数、補助対象、MP、持続を守って全ターンの結果が良くなる場合だけ置き換える。全組合せの最適性を証明するものではない。

`tests/long-support.cjs` で、同じ5ターン編成の八重霞を実在アンコールへ置換すると、全行動・MPを払った上で総ダメージが増えること、所持品と実測攻撃力を保つこと、連鎖追加行動のまとまり、MP内で強い攻撃を使うことを確認する。これは実機バハムートのダメージ再現ではない。
