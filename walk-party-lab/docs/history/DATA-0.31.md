# 0.31 白いこころの枠別補正

確認日：2026-10-23。

いびつ世界の幻竜の通常S（紫）と覚醒S（白）を追加。各1個を比較用の新規所持候補とし、既存の所持数・レベルは保持する。通常・覚醒の同時装備は禁止。覚醒はHP/MP144、攻撃/守備/攻魔/回魔/速度136、器用114、コスト167・最大コスト+4。通常MP回復3、覚醒MP回復4を既存の通常行動前の固定回復モデルへ接続。

白の能力補正をdomain/battle/heart-stats.jsへ分離した。赤は攻撃、黄は守備、紫は攻魔、緑は回魔、青は速度を単色枠で2倍。複合枠は対応能力に+0.5、白/虹は全能力1.15倍（赤白なら攻撃1.65倍）。黒単色枠では補正なし。白は切上げ、通常こころは従来の色一致倍率・切捨てを維持する。プラ魂/ウラ魂などの追加値は含めない。

装備計算と白の初期候補評価に同じ補正を使用する。表示は一律の倍率ではなく能力別の倍率を示す。全最適解を保証する探索への変更ではない。旧solverにも白の能力寄与を接続し、現行のWorker入口で共通処理を読み込む。

呪文・ブレス・回復技、白の新世界の解除防止・耐久、追い覚醒・覚醒+個体差の完全再現は未完了。収録された攻撃補正と固定MP回復だけを現行計算へ接続する。

新規こころで候補の絞り込みが変わるため、討伐候補が出ない場合は幻竜なしの所持品条件でも再探索する。所持記録そのものは変えない。探索件数は合算し、再比較した旨を結果の前提へ記録する。大域最適性を保証するものではなく、再比較時は計算時間が増える。
